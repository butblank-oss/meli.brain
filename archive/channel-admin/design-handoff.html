01 무엇을 만드는가

맬리브레인은 지자체 치매안심센터가 주민에게 제공하는 인지건강 앱입니다. 참여자는 매일 앱에서 두뇌훈련·재활운동·마음다루기 활동을 수행하고, 담당 주무관이 그 현황을 관리합니다.

지금은 하나의 어드민에 권한만 나뉘어 있습니다. 이것을 채널관리자용(지자체 담당 주무관)과 슈퍼관리자용(원메딕스 운영팀)으로 분리하는 것이 사업 확장의 전제이며, 이 문서는 그중 채널관리자 어드민을 다룹니다.

이 어드민의 존재 이유는 월간 리포트입니다. 현재 원메딕스가 매달 손으로 만들어 보건소에 보내는 자료를, 주무관이 화면에서 직접 내려받게 만드는 것. 나머지 화면은 그 리포트에 들어갈 숫자를 확인하고 참여자를 관리하는 수단입니다. 디자인 우선순위도 이 순서를 따릅니다.

B2B 제품이라는 점

이 어드민은 향후 다른 지자체에 판매됩니다. 따라서 디자인은 다음을 만족해야 합니다.

  • 기관 색상 교체가 쉬울 것 — 강조색 토큰 하나를 바꾸면 전체가 따라오는 구조
  • 기관명·기수가 데이터 — "인천 남동구 치매안심센터", "3기"는 하드코딩된 문구가 아니라 채널마다 바뀌는 값
  • 공공기관에서 쓰인다 — 화려함보다 신뢰감, 밀도 높은 표, 명확한 상태 표시

02 사용자와 사용 맥락

주 사용자 — 담당 주무관

인천 남동구 치매안심센터 소속 공무원. 이 앱 사업은 담당 업무의 일부이며, 하루 종일 이 화면을 보지 않습니다.

아침에 잠깐 열어 "오늘 처리할 게 있나" 확인하고, 월초에 보건소 제출 자료를 만듭니다.

업무용 노트북, 1440×900 안팎. 모바일 사용 없음.

부 사용자 — 원메딕스 운영팀

같은 화면을 볼 수 있지만 권한이 다릅니다. 상담 이관을 받거나, 채널관리자가 못 하는 작업(일정 변경, 챌린지 생성)을 대신합니다.

화면상 소속이 원메딕스 (운영팀) 로 구분 표시됩니다.

사용 빈도로 본 메뉴 구조

사이드바가 사용 빈도순 3그룹으로 묶여 있습니다. 이 위계는 디자인에서 유지되어야 합니다.

그룹메뉴빈도성격
운영오늘 · 참여자 · 활동 현황 · 상담실매일확인하고 처리
프로그램프로그램 일정 · 챌린지가끔읽기 전용 — 변경은 운영팀에 요청
행정월간 리포트 · 참여 신청 · 열람 기록월 1회 / 기수 시작 시문서를 만들고 증빙을 남김
읽기 전용 메뉴는 "막힘"으로 끝나면 안 됩니다. 프로그램 일정과 챌린지는 채널관리자가 수정할 수 없지만, 각 화면에 변경 요청 경로가 반드시 함께 있어야 합니다. B2B에서 "안 됩니다"만 있는 화면은 클레임이 됩니다.

04 화면별 명세

공통 뼈대

모든 화면이 같은 껍데기를 씁니다.

영역크기구성
사이드바238px 고정제품명 → 채널 스위처(기관명·기수·D+일수) → 3그룹 메뉴 → 하단 사용자 정보
상단바sticky화면명 + 하단에 작은 경로(기관 · 기수) / 우측에 월 선택(해당 화면만) + 사용자 배지
본문padding 18/24카드 세로 배치, 카드 간격 18px
월 선택은 활동 현황·월간 리포트에만 나타납니다. "오늘" 대시보드에 월 선택이 있으면 안 됩니다 — 대시보드는 언제나 현재 시점입니다.

1. 오늘

주무관이 아침에 여는 화면. "할 일이 있나 없나"에 3초 안에 답해야 합니다.

  • 지표 타일 5개 — 3기 대상자 / 이번 주 활동자 / 어제 활동 / 14일+ 무활동 주의 / 미처리 신청 위험. 각 타일에 전기 대비 증감
  • 처리할 일 — 원형 아이콘 + 제목 + 설명 + 우측 액션 버튼. 3행. 마지막 행만 강조 버튼
  • 최근 14일 추이 — 막대 스파크라인, 주말은 회색
  • 관심이 필요한 참여자 — 이름(링크) / 사유 태그 + 근거 / 경과 / 연락 버튼

2. 참여자

필터가 이 화면의 핵심입니다. 4단으로 쌓입니다.

  1. 검색줄 — 검색 입력 + 검색 항목 선택 + 연령대 + 성별
  2. 상태 — 참여 중 / 중도포기 / 만료 / 회원탈퇴 (칩, 복수 선택, 각 칩에 건수)
  3. 기관 — 복지관 5종 (칩, 복수 선택)
  4. 활동 — 오늘 수행 / 최근 활동 / 7일 무활동 / 14일+ 무활동 / 무활동 (칩, 복수 선택)

필터 아래 결과바(조건에 맞는 N명 + 초기화 + 단체 메시지 + 내려받기), 1명이라도 체크하면 그 아래 일괄작업바가 강조색으로 나타납니다.

표 12열: 체크박스 · 이름 · PIN · N · 연락처 · 생년 · 기관 · 상태 · 활동일 · 수행률 · 최근 이용 · 앱.

PIN은 전화 응대 시 본인 확인용 조회번호, N은 오늘 수행한 활동 수입니다(0이면 빈칸, 있으면 강조색 배지). 둘 다 실제 어드민에 있는 컬럼이라 유지해야 합니다.

3. 참여자 상세

모달이 아니라 독립 화면입니다. 좌상단 "← 목록"은 들어온 곳(참여자 / 활동 현황 / 챌린지 상세)으로 되돌아갑니다.

헤더

이름 · 생년 · 성별 · PIN · 상태 배지 / 우측에 정보 수정 · 상담 열기 · 탈퇴 처리(빨간 외곽선). 그 아래 정보 2열 — 참여자 ID, 연락처, 담당 복지관, 담당상담사, 로그인방식, 앱 버전 / 가입일, 최근 이용, 누적 활동일, 수행률, 연속 출석, 랭킹 점수.

탭 ① 활동 내역 — 가장 중요한 화면

2단 구성입니다. 왼쪽은 패턴, 오른쪽은 그날 상세.

  • 왼쪽 (312px) — 활동 밀도 달력: 월 달력의 각 날짜가 활동량에 따라 강조색 농도로 칠해짐 (0회 회색 / 1–2 / 3–4 / 5회+). 월 이동 화살표, "최근 활동일" 버튼, 하단에 이번 달 활동 일수·총 횟수. 기수 기간 밖은 비활성
  • 오른쪽 — 선택한 날: ◀ 8월 19일 (수) ▶ 헤더 → 요약 타일 4개(활동/걸음 수/마음 상태 기록/증상 기록) → 시각순 기록 리스트

기록 리스트의 한 행: 오전 8시 28분 / 활동명 + 점수 + 출처("두뇌운동 치매예방교실-26년") / 우측 달성률 %. 운동 활동은 그 아래로 동작별 하위 기록이 들여쓰기로 펼쳐집니다 — 좌측 세로선, 분 단위 시각, 동작명(좌/우 구분 포함), 개별 달성률. 중단된 동작은 빨간 0.

재활운동 동작별 기록이 이 제품의 차별점입니다. 다른 인지건강 앱은 "운동 완료 100%"로 끝나지만 맬리브레인은 "고양이 자세로 어깨 늘리기, 왼쪽 100%"까지 남습니다. 디자인에서 이 계층이 잘 읽히도록 해주세요.

탭 ② 검사 이력

표: 검사일시 · 검사명 · 점수 · 판정 배지 · 직전 점수 · 변화(▼3 호전 / ▲6). 최신순. 검사 날짜가 반드시 보여야 합니다.

탭 ③ 챌린지 참여

참여 중인 챌린지마다 카드 — 이름 + 성공/진행 중 배지 + 달성일 N/기준일 + 일별 달성 미니 캘린더 + 달성 상세 버튼.

4. 활동 현황 (6탭)

탭내용
종합지표 타일 8 + 기관별 참여 표(막대) + 참여 강도 분포(가로 막대 5구간)
참여 지속핵심 지표 4 + 코호트 잔존율 히트맵(3색) + 이탈 직전 콘텐츠 + 이탈 전조 신호 표
활동 패턴요일별 막대 + 시간대별 막대(06–09시 강조) + 요일×시간대 히트맵
콘텐츠유형별 완료율 표 + 두뇌훈련 인기 순위(순위 막대) + 완료도 구성 3타일
개인별기간·검색·정렬 + 11열 랭킹 표 + 페이저. 이름 클릭 → 참여자 상세
판정 기준지표 정의 표 + 확인 필요 항목 빨간 박스
"판정 기준" 탭을 장식으로 보지 마세요. 보건소에 제출한 숫자와 화면 숫자가 다를 때 주무관이 여는 화면입니다. 표가 읽기 쉬워야 하고, 계산식은 고정폭 글꼴로 보여야 합니다.

5. 월간 리포트

2단. 왼쪽 320px — 포함 항목 체크리스트(6개, 각 항목에 설명 + 데이터 출처 태그. 자동 생성 불가 항목은 빨간 태그) / 서식 선택 / 내려받기 버튼 3종. 오른쪽 — 실제 공문 미리보기. 체크를 끄면 해당 절이 즉시 사라집니다.

공문 미리보기는 종이 문서처럼 보여야 합니다 — 가운데 정렬 제목, 수신·발신 한 줄, 굵은 가로선, 좌측 강조색 세로선이 붙은 절 제목, 촘촘한 격자 표.

6. 상담실

3분할 · 높이 560px. 방 목록(262px) / 대화 / 참여자·담당 정보(320px).

답변 입력창은 조건부입니다. 그 방의 담당자로 지정된 사람에게만 나타나고, 아니면 입력창 자리에 "이 상담실은 원메딕스 운영팀이 담당하고 있어 답변할 수 없습니다 + 담당 가져오기" 안내가 들어갑니다. 이건 현재 시스템의 실제 제약이라 디자인으로 숨기면 안 됩니다.

7. 프로그램 일정

월 달력, 일요일 시작 (일월화수목금토). 일요일 헤더는 빨강, 토요일은 파랑. 평일 칸마다 활동 3~4개가 색상 칩으로: 두뇌훈련(강조색) / 운동(초록) / 마음다루기(주황) / 검사측정(파랑). 운동 칩만 클릭 가능하며 세부 운동 목록 모달이 열립니다. 하단에 범례 + 이번 달 편성 건수.

8–9. 챌린지 / 챌린지 상세

목록은 표(챌린지 · 종류 · 기간 · 달성 조건 · 참여 · 성공 · 성공률 · 상태). 달성 조건 칸은 사람 말로 씁니다 — "수업일 중 15일 이상 출석 / 하루 추천 활동 2개 이상 = 그날 출석".

상세는 조건 요약 2열 + 달성/진행/미참여 막대 3개 + 일별 달성 스파크라인(주말 회색) + 참여자별 달성 표(진행 막대 포함) + 페이저. 행 클릭 → 달성 상세 모달.
