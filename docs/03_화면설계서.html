  • 스크롤 힌트 — 섹션마다 하나씩 있어 스크롤과 함께 지나갑니다. 8개 힌트는 서로 다른 8개 요소입니다.

812를 넘기면 화면을 나눕니다. 콘텐츠가 한 화면을 넘으면 카드를 줄이는 대신 화면을 분리합니다. 이 원칙으로 SC-RP-04가 04와 04B로 갈라졌고, 05 · 06은 중복 요소를 덜어 한 장에 맞췄습니다. 812는 타협 대상이 아닙니다.

14. 화면별 검수 체크리스트

SC-RP-01 커버

  • ☐ 참여일 0일 계정에서 "242일 중 0일"이 그대로 나오는가
  • ☐ 커버에서 07까지 스크롤하는 동안 X 버튼이 계속 우상단에 떠 있는가 (섹션마다 새로 그려지지 않는가)
  • ☐ 이름 미설정 계정에서 "회원님,"이 나오는가 ("회원님 님" 아님)
  • ☐ 응답 payload에 원문 이름이 없는가
  • ☐ 배지와 헤딩이 가운데 정렬인가 (02~06은 좌측 정렬)

SC-RP-02 숫자 요약

  • ☐ 뇌 점수가 F-08로 나올 수 있는 14개 값 중 하나인가 (68 · 76은 불가)
  • ☐ 측정 1회 계정에서 없는 쪽이 "–점"으로 나오는가 (감추지 않았는가)
  • ☐ 꺾은선이 카드 좌우 끝까지 이어지는가
  • ☐ 마음 기록 단위가 "일"인가 ("회" 아님)
  • ☐ 참여일 0 계정에서 카운트업이 생략되는가

SC-RP-03 집중 리듬

  • ☐ 요일 발생 횟수가 요일마다 다른 값으로 계산되는가
  • ☐ 0% 요일에 트랙과 "0%"가 보이는가
  • ☐ 동률이면 타일이 "골고루"이고 동률 막대가 모두 강조되는가
  • ☐ 시간 동점에서 이른 시간이 뽑히는가
  • ☐ 0시와 12시의 오전 / 오후 변환이 맞는가
  • ☐ 토 · 일이 어디에도 나타나지 않는가

SC-RP-04 게임 하이라이트

  • ☐ 화면 어디에도 점수가 없는가
  • ☐ 게임명이 축약되지 않았는가
  • ☐ S4-03 다크 카드 게임명 = TOP 3 1위 게임명 = S4-04 타일이 세는 게임인가
  • ☐ S4-04 횟수가 SC-RP-02 게임 횟수와 다른 값인가 (게임 하나 vs 전 게임 합)
  • ☐ 1–2종 계정에서 TOP 3가 3행을 유지하고 빈 행이 "게임 기록이 없어요"인가
  • ☐ 0종 계정에서 섹션이 사라지지 않는가

SC-RP-04B 활동 점수 랭킹

  • ☐ 랭킹이 게임 점수가 아닌 활동 점수 기준인가
  • ☐ 타일(S4B-04)과 배지(S4B-06)의 상위 %가 같은 값인가
  • ☐ 두 타일의 가로 폭이 정확히 같은가 (160 / 160)
  • ☐ 1–3위 이름이 마스킹돼 있는가 (블러를 해제해도 실명이 안 보이는가)
  • ☐ 내 순위가 1–3위일 때 내 행만 선명하고 나머지 두 행은 블러가 남는가
  • ☐ 최하위 계정에서 "아래로 N명" 문구가 사라지는가
  • ☐ 구분선에 구간 문구가 없는가

SC-RP-05 마음 기록

  • ☐ 시작 · 종료 점수의 위계가 크기가 아닌 투명도로 만들어졌는가
  • ☐ 게이지가 정확히 180° 반원인가 (좌 끝 = 0점, 우 끝 = 15점)
  • ☐ 바늘이 가리키는 구간과 종료 점수의 K-12 구간이 일치하는가
  • ☐ 구간 숫자가 설정값에서 오는가 (하드코딩 아님)
  • ☐ 상태 텍스트가 양호 / 주의 / 위험 중 하나이고 양호일 때만 녹색인가
  • ☐ 측정 1회 · 변화 없음 계정에서 고스트가 안 보이는가
  • ☐ 고스트가 실선보다 옅게 보이는가 (stroke-opacity)

SC-RP-06 걸음수 · 운동

  • ☐ 걸은 날 0일 계정에서 0으로 나누기가 안 나는가
  • ☐ 하루 평균의 분모가 걸은 날 수인가 (참여일 아님)
  • ☐ 1만보 초과 계정에서 중앙 숫자가 실제값(124%)이고 아크만 100%에서 멈추는가
