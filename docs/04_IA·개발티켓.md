## 1. 구조 — 리포트는 홈 위의 전체화면 오버레이

리포트는 새 Depth를 만들지 않습니다. **홈 위에 덮이는 전체화면 오버레이 하나**이고, 그 안에 8개 섹션이 세로로 이어진 **단일 스크롤 문서**입니다. 섹션별 페이지가 아닙니다.

| 코드 | 항목 | 정의 |
|---|---|---|
| IA-01 | 리포트 오버레이 | 홈 위 전체화면. 하단 탭바에 가리지 않고 전체 높이 사용. 8개 섹션 단일 스크롤 |
| IA-02 | 홈 배너 | 홈 상단 카드형 1개. 오버레이 진입 경로 |
| IA-03 | 4기 신청 결과 | SC-RP-08. 리포트 오버레이 안에서 전환되는 결과 화면 (새 Depth 아님) |

이 구조에서 나오는 두 가지 결과입니다.

- **닫기(X)는 뷰포트 fixed로 전 구간에 인스턴스 하나.** 섹션 내부 absolute로 구현하면 커버에서 스크롤하는 순간 화면 밖으로 밀려나 오버레이를 닫을 수단이 사라집니다.
- **스크롤 힌트는 섹션마다 하나씩** 두고 스크롤과 함께 흘려보냅니다. 아트보드의 X 8개는 같은 버튼 하나를 8번 그린 것이지만, 힌트 8개는 서로 다른 8개 요소입니다.

## 2. 진입 플로우

### F1 — 최초 자동 노출 (11/2)

| 단계 | 화면 | 동작 |
|---|---|---|
| STEP 1 | 11/2 첫 접속 | 앱 실행 · 홈 진입 직후 오버레이 자동 오픈. 사용자 조작 없음 |
| STEP 2 | 리포트 오버레이 | 커버부터 세로 스크롤. 8개 섹션 |
| STEP 3 | 닫기 | 우상단 X 또는 SC-RP-07 "홈으로 돌아가기". 안드로이드 뒤로가기도 동일 |
| STEP 4 | 홈 화면 | 배너가 노출된 상태. 자동 노출은 더 이상 발생하지 않음 |
| STEP 5 | 재진입 가능 | 배너 탭 → F2 경로로 다시 오픈 |

### F2 — 배너 재진입

| 단계 | 화면 | 동작 |
|---|---|---|
| STEP 1 | 홈 화면 | 배너 영역에 "3기 리포트 보기" 노출 |
| STEP 2 | 배너 탭 | 오버레이 오픈. **항상 커버(SC-RP-01)부터** 시작 |
| STEP 3 | 리포트 오버레이 | F1과 완전히 동일한 화면. 분기 없음 |
| STEP 4 | 닫기 → 홈 | 횟수 제한 없이 반복 가능 |

### F3 — 4기 신청 (신설)

| 단계 | 화면 | 동작 |
|---|---|---|
| STEP 1 | SC-RP-07 | "4기도 참여하기 →" 탭 |
| STEP 2 | 07-h 바텀시트 | 하단에서 시트 상승 + 딤. "…프로그램을 신청하시겠습니까?" · [닫기] [네, 신청합니다] |
| STEP 3a | SC-RP-08 | 성공 → "신청이 완료되었습니다." · [홈으로 돌아가기] |
| STEP 3b | 08-a | 실패 → "신청하지 못했습니다." · [다시 시도] [홈으로 돌아가기] |
| STEP 4 | 홈 화면 | 오버레이를 닫고 홈으로 |
| STEP 5 | 재진입 시 | SC-RP-07의 "4기도 참여하기"가 **비활성 + "4기 신청이 완료되었습니다"** (07-l) |

**분기 처리**
- **이미 신청한 사용자** — 확인 시트를 건너뛰고 SC-RP-08 완료 화면으로 직행합니다. 같은 그림을 두 장 두지 않기 위해 별도 아트보드를 만들지 않았습니다.
- **비로그인** — 로그인 유도가 원칙이나, 리포트 진입 자체가 막혀 있어 실질적으로 도달하지 않는 경로입니다.
