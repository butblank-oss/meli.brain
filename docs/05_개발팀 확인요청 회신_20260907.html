나머지 3건은 문서와 일치합니다.

  • 4기 참여 — 앱은 참여 의사만 저장 (apply.season4_applied). 리포트는 이 값으로 07-l 상태를 판단합니다 (IA-R-12).
  • 탈퇴 사용자 — P10 · IA-R-04와 일치. 단 랭킹 모수(K-07)에는 탈퇴자를 포함하며, 탈퇴자가 1–3위에 들면 마스킹된 이름으로 노출됩니다 (D-12 · 의도된 동작).
  • 리포트 생성 1회 + 예외 시 report_version — K-05 재실행과 일치. 1차 열람 후 값이 바뀌는 사용자에게 안내를 붙일지(D-18)는 열어 둡니다 — 배너 자동 노출이 11/2라 실제로는 드뭅니다.
