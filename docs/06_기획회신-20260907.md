| 실제 참여 데이터는 3월 시작 전 생성 | **확인했습니다.** 리포트 범위 밖이며 별도 요청 없습니다 |
| 탈퇴 사용자는 리포트 미노출 | **확인했습니다.** 다만 랭킹 모수(823명)에는 탈퇴자를 포함합니다. 탈퇴자가 1–3위에 들면 마스킹된 이름으로 노출되며, 의도된 동작입니다 |
| 종료 리포트는 원칙적으로 1회 생성 | **확인했습니다.** 10/31 배치 1회에 재검사 입력 지연 시 재실행 1회를 더하는 기존 구조와 같습니다 |
| 예외 시에만 새 리포트 버전 생성 | **확인했습니다.** `generated_at`을 캐시 무효화 기준으로 쓰는 것은 그대로입니다 |

기존 회신에서 "확정사항"으로 정리해 주신 항목 중 두 가지는 아래와 같이 정정합니다.

- **전체 리포트 PNG 저장** — 확정사항이 아닙니다. 저장은 증서 카드 한 장만입니다 (6번 참조).
- **F-11 달성률 반올림** — 제안을 수용해 **반올림**으로 통일합니다. 기존 문서의 "소수점 버림"을 수정했습니다. 표기값에 상한을 두지 않는 것(124%는 124%)과 아크만 100%에서 멈추는 것은 그대로입니다.
