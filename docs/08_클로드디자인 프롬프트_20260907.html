맬리브레인 3기 종료 리포트 프로토타입(맬리브레인 리포트 v3)에 2026-09-07 확정 사항을 반영해 주세요. 아래 항목만 바꾸고, 나머지 레이아웃·문구·색·모션은 그대로 둡니다. 각 항목은 "어디 → 무엇을 → 어떻게"로 적었습니다.

1. 수료증 화면 (SC-RP-07) — 증서 카드 안

  • 변경: 인천남동구 보건소 (띄어쓰기 이대로)
  • A · B · C 세 분기와 07-d/e/f/g/h/l 변형 전부. 2줄 "발급일 2026년 11월 1일"과 인장 위치는 그대로.
  1. 증서 표기명 (S7-06)
  • 현재: 김*리 님 (마스킹)

2. 걸음수 화면 (SC-RP-06)

  1. 목표 달성률 (S6-05 도넛 중앙 숫자)
  • 산식 하루 평균 ÷ 10,000 × 100의 반올림을 소수점 버림 → 정수 반올림으로. (Math.floor → Math.round)
  • 표기값에 상한 없음(124%는 124%), 아크만 100%에서 멈추는 것은 그대로.

3. 마음 기록 화면 (SC-RP-05) — 검수용 HTML과 동기화 (아직 안 돼 있으면)

  1. 반원 게이지가 145°→20°(125° 스윕)이면 정확한 180° 반원으로. 각도 = 180 − 점수 × 12 (0점 → 좌 180°, 15점 → 우 0°). 중심 (150,150) · 반지름 100 · 스트로크 18 · 바늘 길이 82.
  2. 점선 고스트 바늘의 투명도는 CSS opacity가 아니라 stroke-opacity: .5로. (opacity는 모션 클래스에 덮여 100%로 보입니다.)

4. 데이터 모델 (프로토타입 JS의 목업 데이터)

  1. 사용자 객체에 masked_name: "김*리"와 별도로 cert_name: "김맬리"를 두고, 증서(S7-06)에서만 cert_name을 씁니다. 다른 화면은 계속 masked_name.
  2. 표기명 우선순위는 닉네임 → 이름 → "회원님". 마스킹 규칙은 첫 글자·끝 글자만 남기고 가운데 전부 * (김맬리 → 김*리, 남궁민수 → 남**수, 김맬 → 김*, 1자는 그대로). 커버·랭킹 표시에 이 함수를 쓰고, 증서는 통과시키지 않습니다.
  3. 랭킹 상위권 3행: 동점 그룹이 3명을 넘으면 본인 → 참여일 많은 순 → 가입일 빠른 순으로 3명. 순위 숫자는 모두 같은 값.
