## 2. 걸음수 화면 (SC-RP-06)

4. **목표 달성률 (S6-05 도넛 중앙 숫자)**
   - 산식 `하루 평균 ÷ 10,000 × 100`의 반올림을 **소수점 버림 → 정수 반올림**으로. (`Math.floor` → `Math.round`)
   - 표기값에 상한 없음(124%는 124%), 아크만 100%에서 멈추는 것은 그대로.

## 3. 마음 기록 화면 (SC-RP-05) — 검수용 HTML과 동기화 (아직 안 돼 있으면)

5. 반원 게이지가 145°→20°(125° 스윕)이면 **정확한 180° 반원**으로. 각도 = `180 − 점수 × 12` (0점 → 좌 180°, 15점 → 우 0°). 중심 (150,150) · 반지름 100 · 스트로크 18 · 바늘 길이 82.
6. 점선 고스트 바늘의 투명도는 CSS `opacity`가 아니라 **`stroke-opacity: .5`**로. (`opacity`는 모션 클래스에 덮여 100%로 보입니다.)

## 4. 데이터 모델 (프로토타입 JS의 목업 데이터)

7. 사용자 객체에 `masked_name: "김*리"`와 별도로 **`cert_name: "김맬리"`**를 두고, 증서(S7-06)에서만 `cert_name`을 씁니다. 다른 화면은 계속 `masked_name`.
8. 표기명 우선순위는 **닉네임 → 이름 → "회원님"**. 마스킹 규칙은 첫 글자·끝 글자만 남기고 가운데 전부 `*` (김맬리 → 김*리, 남궁민수 → 남**수, 김맬 → 김*, 1자는 그대로). 커버·랭킹 표시에 이 함수를 쓰고, 증서는 통과시키지 않습니다.
9. 랭킹 상위권 3행: 동점 그룹이 3명을 넘으면 **본인 → 참여일 많은 순 → 가입일 빠른 순**으로 3명. 순위 숫자는 모두 같은 값.
