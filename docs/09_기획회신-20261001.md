## 3. 4기 신청 — 정책서 F3 · 07-h · SC-RP-08 · IA-R-12 참고 부탁드려요

"4기 챌린지가 아직 없어 버튼이 보이지 않는다"는 부분은 저희가 생각한 범위와 조금 다른 것 같아요. 9/7 회신 §2에서 "4기 참여는 앱에서 **참여 의사만 저장**"으로 함께 확인했던 내용이라, 아래처럼 진행 부탁드려요.

- "4기도 참여하기" 버튼은 **10/27 출시부터** 수료증 화면(S7-11)에 노출해 주세요.
- 흐름은 정책서 그대로입니다: S7-11 탭 → 07-h 바텀시트 → SC-RP-08 완료 / 08-a 실패 → 재진입 시 07-l(버튼 비활성 + "4기 신청이 완료되었습니다").
- 신청 여부는 `apply.season4_applied` 서버 값으로 판단합니다(IA-R-12).
- 저장된 신청 의사는 나중에 4기 운영 때 승인 목록으로 옮길 수 있는 형태로만 쌓아 주시면 됩니다.
- 9/29 신청폼의 승인 플로우(대기 · 즉시, 모집 조건, 반려 후 재신청, 대리 등록)와는 별개라 이번 리포트 범위에는 넣지 않습니다. 4기 운영 때 따로 정리할게요.

문구는 정책서 그대로 쓰고 한 줄만 추가 부탁드려요.

- SC-RP-08 완료 본문(S8-05) → "**4기가 시작될 때 보건소에서 연락드리겠습니다.** 자세한 문의사항은 {전화번호}로 문의 바랍니다. 감사합니다."

## 5. §4 기본값 중 확인 부탁드릴 것

- **"리포트를 못 찾을 때 2번 문구 사용"** → 정책서 P09(배치 미완료: "리포트를 준비하고 있어요")와 P18(네트워크 오류: 전체 화면 안내 + [다시 시도])로 나눠 주세요. 3기 참여자인데 데이터 문제로 못 찾는 경우에 "참여자에게만 제공됩니다"라는 문구가 나가면 오해가 생길 수 있어서요.
- **기존 "프로그램 종료 작별 화면" 팝업 폐기** → 정책서에 없던 변경이라, 리포트가 없는 다른 프로그램 종료자에게 어떤 영향이 있는지 공유해 주시면 확인 후 회신드리겠습니다.
- **B분기 저장 버튼 "참여기록 저장하기"** → 확정입니다(Q-02 종결).
- 나머지 §4 항목은 말씀해 주신 기본값대로 진행해 주세요.
