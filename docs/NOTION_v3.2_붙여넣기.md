# 노션 반영용 — v3.2 (2026-10-01)

노션 기획서 v3.1(9/8)을 v3.2로 올릴 때 바꿀 곳만 모았습니다. 위치는 노션 페이지의 해당 코드(K · F · P · IA · D · Q)로 찾으면 됩니다.
레포 정본(`docs/01~04`, `07_변경이력`, `09_기획회신-20261001`)과 피그마에는 이미 반영돼 있습니다.

---

## 1. 판 표기

- 문서 상단 판 표기: `최종판 v3.1 · 2026-09-07` → **`최종판 v3.2 · 2026-10-01`** (v3.1 2026-09-07 기반)
