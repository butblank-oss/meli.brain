Q0. 이 사업에서 개인정보 처리자가 누구입니까?

이것에 따라 동의서의 명의·구조·보유기간이 전부 달라집니다. 가장 먼저 답이 필요합니다.

(가) 원메딕스가 처리자 (나) 남동구 보건소가 처리자
구조 원메딕스가 수집 → 보건소에 제3자 제공 보건소가 수집 → 원메딕스는 수탁자
동의 명의 원메딕스 (맬리브레인) 인천 남동구 보건소
필요한 동의 이용약관 + 개인정보 수집·이용 + 제3자 제공 보건소 수집·이용 동의 (제3자 제공 불필요)
보유기간 기준 회원 탈퇴 시까지 (맬리 기준) 지자체 기록물 보존 기준
처리방침 개정 원메딕스 처리방침에 보건소 제공 명시 보건소 개인정보파일 등록 필요
현재 초안 이 구조로 작성돼 있음 —

판단 근거로 필요한 것: 남동구 보건소와 맺은 계약 형태 (용역계약 / 위탁계약 / 민간 자체사업 + 협약). 계약서에 "개인정보 처리 위탁" 조항이 있으면 (나)일 가능성이 높습니다.

실무에서는 (다) 혼합형도 흔합니다 — 맬리 회원가입은 원메딕스가 처리자, 치매예방교실 참여 정보만 보건소에 제공. 현재 초안이 이 구조에 가장 가깝습니다. 다만 자동 승인이 "보건소가 승인한 것으로 간주"하는 구조라면 (나)에 가까워집니다.

B. 확인·결정이 필요한 것 (9)

# 질문 왜 필요한가 기본값 제안
B-01 보건소가 수집하는 법적 근거 법령이 있습니까? (치매관리법 · 지역보건법 등) 법령 근거가 있으면 §15①2(법률 규정)로 처리 가능해 동의 부담이 줄어듭니다. 없으면 전부 동의 기반 동의 기반으로 작성
B-02 치매예방교실 참여 사실 · 인지검사 결과를 민감정보로 볼 것인가? 건강정보는 §23 민감정보. 해당하면 별도 동의 1건 추가 (필수 4개가 됨) 법무 판단 필요. 신청폼 자체는 건강정보를 안 받으므로 현재는 미포함
B-03 회원가입 연령 하한은? 만 14세 미만이면 법정대리인 동의 필요(§22-2). 현재 폼에 연령 확인이 없음 만 14세 이상 (실질 대상은 고령층)
B-04 변경 마케팅 수신 채널 범위 신청폼에서 선택 동의를 삭제했습니다. 앱에서 광고성 정보를 보낸다면 앱 안에서 별도 동의를 받아야 합니다 처리방침의 마케팅 목적은 아직 남아 있음 → 2차 검토 M-5
B-05 수신 동의 2년 주기 확인(정보통신망법 §50⑧) 프로세스가 있습니까? 법정 의무. 없으면 신설 필요 앱 알림으로 처리
B-06 보건소 직원 대리 작성의 법적 절차를 보건소와 합의했습니까? 동의는 정보주체 본인이 해야 합니다. 현재 설계는 "직원은 입력만 대행, 동의는 본인이 직접 터치" 현재 설계 유지 + 기록 저장
B-07 부분해결 보건소 제공분의 보유기간 — 지자체 기록물 보존 기준은? "사업 종료 후 3년"으로 확정되어 처리방침·동의서가 일치합니다 3년의 근거를 보건소에서 확인만 받으면 됩니다
B-08 3기 → 4기 이어서 참여 시 이전 기수 기록을 보건소에 계속 제공합니까? 제공 항목·기간에 영향 제공 (연속 사업으로 봄)
B-09 타 기관 확장 시 동의서를 기관별로 분리합니까? 제3자 제공 동의는 제공받는 자를 특정해야 해서, 기관마다 별도 문안이 필요합니다 기관별 분리

C. 기존 문서와 어긋나 개정이 필요한 것 (8) ★

여기가 핵심입니다. 지금 문서 그대로는 신청폼을 못 엽니다.

C-01. 거주 행정동이 수집 항목에 없음 필수
현행 처리방침 제3조 필수항목 = 이름, 생년, 성별, 휴대전화번호
신청폼 이름, 휴대전화번호, 거주 행정동
문제 거주 행정동이 처리방침 어디에도 없습니다. 고지 없이 수집하는 상태가 됩니다
조치 처리방침 제3조에 거주 행정동(시·군·구·읍면동) 추가. 수집 목적에 "관내 거주 확인" 명시

C-02. 생년 · 성별을 신청폼에서 받지 않음 필수
현행 처리방침 제3조 필수항목에 생년·성별이 있음
신청폼 받지 않음. 그런데 회원 생성까지 일어남
문제 필수항목 없이 회원이 만들어져 처리방침과 실제가 어긋납니다
조치 둘 중 하나 — (가) 신청폼에 생년·성별 추가 (시니어 입력 부담 증가, 권장하지 않음) / (나) 처리방침을 "가입 경로별 수집 항목"으로 분리 기재 (권장)

참고: 제3조 2항 선택항목에 이름·성별·생년월일이 중복으로 들어가 있습니다. 필수항목과 겹쳐서 어느 쪽이 맞는지 불명확합니다. 이 기회에 정리가 필요합니다.

C-03. 제3자 제공에 남동구 보건소가 없음 필수
현행 처리방침 제4조는 원칙만 기술. 제공받는 자 목록이 없음
신청폼 보건소에 이름·전화번호·거주동·출석·수료 여부를 제공
문제 개인정보보호법 §17②는 제공받는 자 · 목적 · 항목 · 보유기간 · 거부권과 불이익을 모두 알리도록 요구합니다
조치 처리방침 제4조에 제3자 제공 표 신설. terms.html의 필수 3번 항목이 그 내용입니다

제25조(통계분석 자료의 가공과 제공)의 "요양기관 · 공공기관 제공"은 비식별 통계라 이것과 별개입니다. 실명 정보 제공 근거로 쓸 수 없습니다.

C-04. 보유기간이 서로 다름
현행 처리방침 제2조 2항 = 회원 탈퇴 시까지
초안 사업 종료 후 1년
문제 같은 데이터에 두 기준이 존재합니다
조치 맬리 보유분(회원 탈퇴 시까지)과 보건소 제공분(지자체 기록물 기준)을 분리 기재. 보건소 기준은 B-07에서 확인

C-05. 서버 운영 위탁사가 누락
현행 처리방침 제5조 위탁 표에 NHN Cloud (SMS·알림톡)만 있음
실제 서버·DB를 어딘가에서 운영하고 있을 것
문제 위탁 사실 미고지. §26 위반 소지
조치 실제 클라우드 사업자를 위탁 표에 추가 (A-07). 국외면 §28-8 국외이전 고지 별도 (A-08)

C-06. 아이디 · 비밀번호 조항이 전화번호 로그인과 충돌
현행 이용약관 제8조 전체가 아이디·비밀번호 관리 의무를 전제
신청폼 전화번호만으로 로그인. 비밀번호가 없음
문제 존재하지 않는 수단에 대한 회원 의무를 지우고 있습니다
조치 제8조에 항 신설 — "전화번호 인증 방식으로 가입한 회원의 경우 전화번호가 식별수단이 되며, 번호 변경·양도 시 지체 없이 통지해야 한다"

번호 재사용(전 소유자 계정) 문제의 약관상 근거도 여기서 확보됩니다.

C-07. 이용계약 체결 시점이 자동 승인과 맞지 않음
현행 이용약관 제5조 1항 = 회원가입 신청 + 회사의 승낙으로 체결
신청폼 제출 즉시 자동 승인 (= 즉시 승낙)
문제 승낙 시점이 불명확합니다. 자동 승인의 약관상 근거가 없습니다
조치 제5조에 항 신설 — "기관 전용 신청폼을 통한 가입은 제출 시점에 승낙한 것으로 본다. 다만 제2항 각 호에 해당하는 경우 사후에 이용계약을 해지할 수 있다"

제5조 2항 2호 "실명이 아니거나 타인의 명의를 이용한 경우"가 타인 번호로 신규 접수한 건을 사후 정리하는 근거가 됩니다. 미로그인 30일 계정 자동 정리의 약관 근거로 쓰세요.

C-08. 대리 작성 규정이 어디에도 없음
현행 이용약관 · 처리방침 어디에도 제3자 대리 작성 규정이 없음
신청폼 보건소 직원이 대신 입력하는 경로가 있음
문제 동의는 정보주체 본인이 해야 합니다. 직원이 동의까지 대신 누르면 동의가 무효가 될 수 있습니다
조치 개인정보 수집·이용 동의서에 명시 — "직원이 대신 입력한 경우에도 동의는 본인이 직접 해야 유효하며, 대리 입력 사실·직원 식별자·동의 시각을 함께 기록한다". 직원 식별 수단은 별도 결정 필요
