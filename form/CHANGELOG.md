# 변경이력

인천 남동구 보건소 치매예방교실 신청폼 개편 산출물의 판올림 기록입니다.

**버전을 끊는 기준** — 외부(기획자·개발팀·보건소)에 전달한 시점에 번호를 올리고 파일을 박제합니다.
박제된 파일은 고치지 않습니다. 그래야 "그때 넘긴 건 이랬다"를 글자 그대로 증명할 수 있습니다.

| 버전 | 날짜 | 상태 | 프로토타입 |
|---|---|---|---|
| **v1.1** | 진행 중 | 작업본 | [`design/index.html`](design/index.html) |
| **v1.0** | 2026-09-21 | 기획자 전달본 · 박제 | [`design/v1.0.html`](design/v1.0.html) |

### 고침

- **열람청구 담당자 박용주 → 안성호** — 확정본 개인정보 처리방침 제11조는 이미 `안성호`인데,
  신청폼 동의서·약관 문안·프로토타입·질의서가 구판(2025-02-26)의 `박용주`를 물고 있었습니다.

> **박제본 예외 반영** — `design/v1.0.html`은 고치지 않는 것이 원칙이지만, 이 건은
> **실제 사람의 이름이 들어간 개인정보 연락처 오기**라 화면 변경이 아니라 사실 정정으로 보고 반영했습니다.
> 박제본에 손을 댄 것은 이 한 곳뿐이며, 앞으로도 이런 사실 정정에 한해서만 예외를 둡니다.

**그대로 둔 것** — `terms/구판_개인정보처리방침_20250226`과 `handoff/원본/`은
그때 실제로 발행·전달된 기록이라 고치지 않습니다. 당시 담당자는 박용주가 맞습니다.

### 확정된 정책

| | 내용 |
|---|---|
| 승인 | **관리자 승인 1회.** 제출은 `PENDING`으로 저장되고 보건소가 승인해야 교실 기능이 열립니다 |
| 반려 | **사유 필수.** 관외 / 정보 불일치 / 중복 / 정원 초과 / 기타. 사유는 신청자 화면에 그대로 보입니다 |

| 동의 | **필수 3개.** 선택 동의는 두지 않습니다 |
| 약관 | 시행일 2026-09-18 · 보유기간 3년 · 이용약관 제4조로 승낙과 이용 개시를 분리 |
| 직원 대리 접수 | 탭이 아니라 **폼 맨 아래 링크**로만 진입. SMS 인증 필수. 동의는 어르신 본인이 |

### 시니어 UX 규칙

- 본문 17px / 입력 19px / 터치 56~64px / 체크박스 34px
- **읽고 조작하는 것은 크게, 맥락만 주는 것은 상한** — 전부 같은 비율로 키우면 헤더가 화면을 다 먹습니다
- 제출 버튼은 **화면 붙박이**. 문서 맨 아래에 두지 않습니다
- 화면이 **저절로 바뀌지 않음** · 첫 화면에 **선택지를 주지 않음** · **막다른 길을 만들지 않음**
- 소요 시간은 **숫자로 약속하지 않음**. "확인이 끝나면"처럼 사건에 묶습니다
- 한국어는 `word-break: keep-all` — 어절 단위로만 끊습니다
- 조상에 `overflow:hidden`을 쓰지 않습니다 (붙박이가 조용히 죽습니다)

### v0.x에서 고친 것

**치명 4건**

- 번호만 넣으면 기존 회원의 **이름·동이 화면에 채워짐** → SMS 인증 통과 전까지 잠금
- **관외 거주자에게 탈출구가 없음** → 동 시트에 두 갈래 추가
- **제출 실패 처리가 없어** 연타 시 두 건 접수 → 제출 중 잠금 + 서버 멱등
- 탭을 옮기면 앞 탭의 확인이 유지돼 **SMS 없이 제출 통과** → 탭 제거 + 모드 전환 시 초기화

**중대 8건** — 첫 화면의 탭 2개, 유효시간 오해, 제출 버튼이 문서 맨 아래, 모든 글자 같은 비율 확대,
중복 신청 시 자동 전환, 비활성 제출 버튼, 입력 중 이탈, 아이폰/안드로이드 선택

**개선 6건** — 별표 대신 배지, 미체크 체크박스를 빈 네모로, 상태 3중 전달,
모두 동의 부제, 시트 포커스 관리, 이름 검증

## 판올림 규칙

1. 외부에 전달할 때 번호를 올립니다. 내부 수정만으로는 올리지 않습니다
2. 올릴 때 `design/index.html`을 `design/v{번호}.html`로 복사해 박제합니다
3. 박제본에서는 **검수 패널의 버전 메뉴만** 현재 버전 표시로 바꿉니다. 화면은 건드리지 않습니다
4. 이 문서에 무엇이 바뀌었는지 적습니다. **되돌린 결정은 왜 되돌렸는지까지** 적습니다
5. 자릿수 — 화면이나 정책이 바뀌면 소수점 첫째 자리, 전체 구조가 바뀌면 정수를 올립니다
