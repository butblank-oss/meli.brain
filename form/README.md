## 1. 무엇이 바뀌나

| | 현재 | 개선안 |
|---|---|---|
| 승인 | 어드민 PC에서 수동 승인 | **제출 즉시 자동 승인** (관내 동 선택이 관외 필터를 대신함) |
| 회원가입 | 신청폼 + 앱에서 또 가입 | **앱 가입 제거**, 신청폼이 회원까지 생성 → 앱은 전화번호 로그인만 |
| 완료 화면 | "곧 문자가 갑니다" 안내만 | **그 자리에서 설치**: 기기 자동 판별 + 스토어 버튼 + QR + 3단계 안내 |
| 주소 | 자유 텍스트 | **인천 남동구 고정 + 관내 20개 동 버튼**, 관외/모름 탈출구 |
| 동의 | 체크박스 1개, 전문 없음 | **필수 3 + 선택 1**, 각 항목 전문 시트 |
| 대리 작성 | 규정 없음 | **직원 모드**(하단 링크로만 진입) + SMS 인증 + 본인 직접 동의 |

## 3. v0.1에서 고친 것 (감사 18건)

**치명 4건**
- 번호만 넣으면 기존 회원의 **이름·동이 화면에 채워짐** → 기존 회원은 SMS 인증 통과 전까지 이름·동·동의를 잠금
- **관외 거주자에게 탈출구가 없음** → 동 시트에 `남동구에 살지 않아요`·`잘 모르겠어요` 추가
- **제출 실패 처리가 없어** 연타 시 두 건 접수 → 제출 중 잠금 + 실패 시 입력값 보존 + 서버 멱등
- 탭을 옮기면 앞 탭의 확인이 유지돼 **SMS 없이 제출 통과** → 탭 제거 + 모드 전환 시 초기화

**중대 8건**
- 첫 화면의 탭 2개 → 직원 모드를 하단 링크로 숨김
- 유효시간 5분인데 재발송 쿨다운 `30초`만 보여 **30초인 줄 오해** → `4:32` 카운트다운 상시 노출, 문장 분리
- **제출 버튼이 문서 맨 아래**라 스크롤해야 보임 → 화면 붙박이 + `아래에 더 있어요 ▾`
- **모든 글자를 같은 비율로 확대**해 헤더가 첫 화면을 다 먹음 → 역할별 확대 정책
- 중복 신청 시 1.2초 자동 전환 → 버튼으로 변경
- 비활성 제출 버튼 → 항상 활성 + 빠진 곳으로 데려감
- 입력 중 이탈하면 전부 사라짐 → 24시간 임시저장 (직원 모드 제외)
- 아이폰/안드로이드를 어르신이 고름 → UA 자동 판별

**개선 6건** — 별표 대신 `꼭 적어주세요` 배지, 미체크 체크박스를 빈 네모로, 상태를 색+아이콘+문구 3중 전달,
"모두 동의"가 선택 항목까지 켠다는 명시, 시트 포커스 관리·ESC·뒤로가기, 이름 검증.

상세 근거와 코드는 [`ia.html` §2](ia.html)에 있습니다.

## 4. 시니어 UX 핵심 규칙

- 본문 17px / 입력 19px / 터치 56~64px / 체크박스 34px
- **읽고 조작하는 것은 크게, 맥락만 주는 것은 상한** — 전부 같은 비율로 키우면 헤더가 화면을 다 먹음
- **주요 버튼은 문서 맨 아래에 두지 않음** — 스크롤 개념이 약한 대상이라 붙박이가 기본
- 화면이 **저절로 바뀌지 않음**, 첫 화면에 **선택지를 주지 않음**, **막다른 길을 만들지 않음**
- 한 문장 40자 이내 · 명사 나열 금지 · 색으로 지칭 금지 · 실패를 사용자 탓으로 돌리지 않음
- 조상에 `overflow:hidden`을 쓰지 않음 (붙박이가 조용히 죽음)

## 5. 서버가 반드시 해야 하는 것

1. 조회 API **레이트 리밋** — 없으면 번호 대입으로 참여자 명단을 캐낼 수 있음
2. 조회 응답에 **이름·거주 동을 절대 포함하지 않음** — 화면을 잠가도 응답에 있으면 무의미
3. 인증번호 검증·시도 횟수·잠금·쿨다운을 **전부 서버에서**
4. 제출 시 `dongCode`를 **관내 화이트리스트로 재검증**
5. 제출 **멱등 처리** — 같은 번호는 기존 건 반환
6. **미로그인 30일 계정 자동 정리** — 타인 번호 신규 접수의 유일한 방어
7. 동의 저장 시 **항목별 동의·시각·약관 버전·작성 경로** 기록

전체 10건은 [`ia.html` §9](ia.html).
