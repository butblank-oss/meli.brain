신청폼 디자인 체계

대상 60~85세 · 보건소 현장과 집 · 모바일 웹 기준 정부·의료 서비스용 접근성 스타일 (고대비 · 16px 이상 · 보이는 포커스 · 움직임 최소) 검증 아래 색은 전부 대비를 계산해 넣었습니다. 괄호 안이 실제 수치입니다.

1. 지금 쓰고 있던 색 중 기준 미달 4개

여기부터 고쳤습니다. 숫자는 흰 바탕 대비입니다 (글자 4.5 이상 · 테두리와 도형 3.0 이상).

쓰이던 곳 옛 색 대비 바꾼 색 대비
입력칸 자리표시 #AEB5BD 2.07 미달 #6B7680 4.64
잠긴 칸 글씨 #A4ABB3 2.04 미달 #616B75 4.77
입력칸 테두리 #D6D2C9 1.51 미달 #8C877B 3.58
미체크 체크박스 테두리 #B9B4A9 2.07 미달 #8C877B 3.58

체크박스가 안 보인다는 지적의 원인이 마지막 줄입니다. 빈 네모를 그려 놓아도 테두리가 2.07:1이면 흰 바탕에서 거의 사라집니다. 기존 v1.0도 같은 색을 썼습니다.

밝은 그린 #5BBE97 은 흰 글씨를 올릴 수 없습니다 (2.27). 점·막대 같은 표시에만 씁니다.

2. 기준은 proto-4th 입니다

같은 저장소의 맬리브레인 4기 UI 리디자인 v2 가 이미 집 스타일을 정해 두었습니다. 그 문서의 변경점 메모 그대로 — 토스·카뱅식 무테 흰 카드 + 회색 배경입니다. 신청폼도 여기에 맞춥니다 (v2.html?look=p4).

토큰 값 흰 바탕 대비 쓰는 곳
--key #0A6B47 6.55 주요 버튼 · 고른 상태 · 링크
--soft #EAF4EE — 번호 타일 · 안내 카드 바탕
--mint #13BD7E 2.44 글자로 쓰지 않습니다. 점·막대에만
--ink #191F28 16.56 제목 · 본문
--ink2 #5C6675 5.81 도움말 · 캡션
--line #E6EAF0 1.3 장식 구분선
--line-strong #7A8494 3.78 누르는 칸의 경계
--bg / --card #F2F4F6 / #FFFFFF — 회색 배경 / 무테 흰 카드
  • 카드는 테두리도 그림자도 없습니다. 흰 면과 회색 배경의 차이로만 구분합니다.
  • 머리말을 색면으로 덮지 않습니다. 흰 바탕에 큰 먹 제목, 색은 버튼에만 씁니다.
  • 글자는 제목 23 · 라벨 19 · 입력 19 · 본문 17 · 캡션 15 (proto-4th 의 19~22 / 18 / 15 와 같은 결).

한 가지만 일부러 다릅니다. proto-4th 는 무테인데, 신청폼의 입력칸과 고르는 칸에는 1.25px 테두리(#7A8494, 3.78:1)를 둡니다. 어르신에게 "여기를 누르세요"의 경계는 양보할 수 없고, 회색 면만으로는 대비가 1.1:1 밖에 되지 않습니다. 카드·구분선은 무테 그대로입니다.

2b. 색 — 역할로만 부른다 (네이비 계열, 초기안)

하드코딩한 색값을 화면 곳곳에 흩어 두지 않습니다. 쓰는 자리마다 이름을 붙입니다.

토큰 값 흰 바탕 대비 쓰는 곳
--key #1F3C5D 11.27 주요 버튼 · 머리말 · 고른 상태
--key-d #16304B — 눌린 순간
--ink #1A1F26 14.93 본문 · 라벨
--ink2 #59636D 6.12 도움말
--ink3 #616B75 4.77 잠긴 칸 글씨
--hint #6B7680 4.64 자리표시
--line-strong #8C877B 3.58 경계가 되는 선 (입력칸 · 체크박스)
--line #E4E1DA 1.31 장식 구분선. 경계에는 쓰지 않는다
--bg / --card #F4F3F0 / #FFFFFF — 바탕 / 입력 카드
--ok / --ok-bg #1C6B4B / #EAF5EF 5.78 됐다는 안내
--warn / --warn-bg #9E241D / #FBEFED 6.85 빠졌다는 안내

색만으로 알리지 않습니다. 상태는 색 · 아이콘 · 문구 세 가지로 같이 말합니다.

3. 말투

화면이 말을 겁니다. 항목 이름을 명사로 세우지 않고 묻는 말로 씁니다 (토스·당근의 결).

전 후
휴대전화 번호 휴대폰 번호를 알려주세요
이름 성함이 어떻게 되세요?
사시는 곳 어디에 사세요?
나이 확인 연세가 어떻게 되세요?
동의해 주세요 마지막이에요
참가 신청 신청을 도와드릴게요
  • 어미는 -해요체. -합니다는 쓰지 않습니다.
  • 시키지 않고 같이 합니다 — "적어주세요"보다 "알려주세요", "확인했습니다"보다 "확인했어요".
  • 어르신을 높입니다 — "나이" 대신 연세, "이름" 대신 성함.
  • 막힌 자리에서는 바로 길을 냅니다 — "번호가 기억나지 않으세요? ›"

4. 글자

토큰 크기 쓰는 곳
--t-h1 25px / 1.32 화면 제목
--t-label 18px / 800 항목 이름
--t-input 19px / 600 입력칸 안
--t-body 17px / 1.7 본문
--t-help 15px / 1.6 도움말
--t-badge 13px / 800 꼭 적어주세요 같은 배지
  • 한국어는 word-break: keep-all + overflow-wrap: break-word. 어절 단위로만 끊습니다.
  • 한 문장 40자 이내. 명사만 늘어놓지 않습니다.

5. 간격과 손

간격은 4의 배수만 씁니다 — 8 · 12 · 16 · 20 · 24 · 32.

토큰 값 비고
--tap 56px 누를 수 있는 것의 최소
--tap-lg 64px 신청하기
--box 34px 체크박스

웹 기준(WCAG 2.2)은 24px, 아이폰 44pt, 안드로이드 48dp입니다. 시니어 기준 56px은 그 위입니다. 붙어 있는 두 버튼 사이는 최소 8px를 둡니다.

6. 포커스와 오류

  • 포커스 — 입력칸은 흰 3px + 키색 3px 두 겹 링. 키보드로 올 때 분명히 보입니다.
  • 오류는 그 칸 자리에서 말합니다. 아래 요약만으로 끝내지 않습니다. 각 칸의 메시지에 role="alert" 과 aria-describedby 를 걸고, [신청하기]를 눌렀을 때 첫 번째 빠진 칸으로 화면을 옮깁니다.
  • 붙박이 버튼 아래의 "아직 남은 것"은 요약입니다. 칸별 메시지를 대신하지 않습니다.

7. 레퍼런스에서 가져온 것 (2026-11-05)

토스 · 당근의 회원가입 흐름을 봤습니다 (유아이볼, 북마크 많은순). 국내에서 가장 많이 참고되는 가입 화면이고, 둘의 방식이 거의 같습니다.

가져온 것

본 것 우리 화면에
입력칸 아래 안심 문구 — "번호는 안전하게 보관되며 어디에도 공개되지 않아요"(당근) "적어주신 번호는 보건소 확인과 안내 문자에만 씁니다"
막혔을 때 빠져나갈 링크를 화면에 상시 노출 — "문자가 안 오나요?"(토스) · "휴대폰 번호가 변경되었나요?"(당근) "번호를 잘 모르시겠어요?" → 보건소 전화 안내
최소 연령을 스스로 고르게 함 — "만 14세 이상이에요 / 만 14세 미만이에요"(당근) "만 60세 이상이에요 / 아직 60세가 안 됐어요". 1차 QA 의 P0-2(나이 미검증)를 이 방식으로 막습니다
주요 버튼은 좌우 여백 + 둥근 모서리 그대로 따릅니다
큰 제목이 말을 건다 — "안녕하세요! 휴대폰 번호로 가입해주세요" 제목 문장을 그 결로 다듬을 여지가 있습니다 (아직 미적용)

가져오지 않은 것

본 것 왜
한 화면에 질문 하나(스텝형) 기획자가 단일 스크롤을 택했습니다. 직원이 옆에서 대신 봐줄 때 한눈에 보여야 합니다
동네를 검색으로 고르기(당근) 타이핑은 어르신에게 가장 큰 벽입니다. 관내 20개 버튼으로 둡니다
현재위치로 찾기(당근) 쓸 만하지만 위치정보 수집 동의가 따로 필요합니다. 별도 검토
선택 동의(마케팅) 이미 걷어낸 결정입니다
PIN · 패턴 · 생체 로그인 우리는 번호 하나로 들어갑니다. 외울 것을 늘리지 않습니다

앞서 적었던 "버튼을 화면 끝에 꽉 차게"는 KB스타뱅킹·키움 기준이었습니다. 최신순 정렬에 걸린 금융 앱들이고, 기획자가 가리킨 토스·당근은 좌우 여백 + 라운드입니다. 레퍼런스를 다시 맞춰 되돌렸습니다.

8. 하지 않는 것

  • 장식적인 그라데이션, 보라·분홍 계열
  • 색만으로 상태 전달
  • 포커스 링 제거
  • 움직임으로 뜻을 전달 (prefers-reduced-motion 을 지킵니다)
  • 자리표시를 라벨 대신 쓰기

9. 다섯 가지 적용안

앞의 둘은 정리이고, 뒤의 셋은 다시 디자인한 것입니다.

성격 무엇이 다른가 보기
A 정리안 정리 지금 그대로, 색·대비·오류만 ?look=a
B 카드형 정리 항목을 흰 카드로 떼고 번호를 붙임 ?look=b
C 종이 안내문 디자인 명조 제목 · 밑줄 입력 · 각진 모서리. 보건소 안내문의 품위 ?look=c
D 큰 색면 디자인 네이비 면 위로 흰 종이가 올라탐 · 큰 번호 ?look=d
E 초록 안심 디자인 맬리브레인 그린 · 모래빛 바탕 · 둥근 카드와 그늘 ?look=e

C의 제목은 Noto Serif KR 500입니다. 한국어 명조는 굵게 쓰면 고딕과 구분이 안 되므로 가는 쪽을 씁니다. 본문은 그대로 Pretendard입니다.
