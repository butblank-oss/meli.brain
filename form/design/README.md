# Handoff: 치매예방교실 4기 신청폼 (맬리브레인 × 인천 남동구 보건소)

## Overview
현장 QR·모집 문자로 진입하는 시니어 대상 신청폼입니다. 기존에는 신청폼과 앱 회원가입이 이중으로 돌아 온보딩이 끊겼습니다. 이 설계는 **신청 = 가입**으로 합치고 관리자 승인 단계를 제거해, 제출 즉시 앱을 쓸 수 있게 만듭니다.

화면은 신청폼 1개 + 결과 4개 + 시트 3개. 두 개의 사용 모드(어르신 직접 / 보건소 직원 대리 접수)가 같은 폼을 공유합니다.

## About the Design Files
이 번들의 HTML 파일은 **HTML로 만든 디자인 레퍼런스**입니다. 의도한 모양과 동작을 보여주는 프로토타입이며, 그대로 가져다 쓰는 프로덕션 코드가 아닙니다.

해야 할 일은 이 HTML 디자인을 **대상 코드베이스의 기존 환경에서 다시 만드는 것**입니다(React, Vue, SwiftUI, 네이티브 등). 그 코드베이스에 이미 자리잡은 패턴·컴포넌트·라이브러리를 사용하세요. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 고른 뒤 그 위에서 구현하면 됩니다.

프로토타입의 전화번호 조회·문자 발송·제출은 모두 setTimeout 기반 목업입니다. 실제 API로 교체해야 합니다.

## Fidelity
**High-fidelity.** 색·타이포·간격·상태·문구가 모두 확정본입니다. 문구는 시니어 대상으로 다듬은 확정 카피이므로 **줄바꿈 위치까지 그대로** 유지하세요. 픽셀 단위로 재현하되, 색·폰트·간격은 코드베이스의 토큰 체계에 매핑해도 됩니다.

미확정 값은 `{전화번호}` 같은 자리표시로 남겨 두었습니다. 아래 "미결정 값" 참고.

글자 크기는 `--fs` CSS 변수(기본 1)로 전역 배율을 받고, 모든 치수를 `clamp(최소, calc(기준*var(--fs)), 최대)`로 선언했습니다. **폼 안에 글자 크기 조절 버튼은 두지 않습니다** — 어르신은 이미 폰 설정에서 키워둔 채로 들어오고, 첫 화면의 선택지를 늘리지 않는다는 원칙에 어긋납니다. 웹에서는 브라우저 확대, 네이티브로 옮길 때는 OS의 동적 글자 크기(Dynamic Type / Font Scale)에 `--fs`를 연결하세요.

## Screens / Views

### SC-F-01 신청폼
**Purpose** — 전화번호·이름·거주동·동의를 받아 신청과 가입을 한 번에 끝낸다.

**Layout** — 세로 단일 컬럼. 위에서 아래로: 헤더(브랜드) → (직원 모드) 모드 띠 → (직원 모드·번호 입력 후) 대상자 바 → 히어로(기관 칩 + 제목 + 설명) → 입력 영역(패딩 26/20/14, gap 28) → 하단 고정 제출 바. 프로토타입 폭 390px.

**Components**
1. **헤더** — 배경 `#fff`, 하단 보더 1px `#E4E1DA`, 패딩 12/18. "매일 이롭게, 맬리브레인" 16px/800/-.035em, 색 `#1F3C5D`.
2. **히어로** — 어르신 모드 배경 `#1F3C5D`, 직원 모드 `#3A342C`. 패딩 20/20/24. 기관 칩(반투명 흰 배경 + 1px 보더, radius 999px, 13px/700) → 제목 2줄 → 설명 15px.
   - 어르신: "치매예방교실 4기 / 참가 신청" + "인천 남동구에 사시는 분만 신청할 수 있어요. / 보건소에서 확인한 뒤 이용하실 수 있습니다."
   - 직원: "치매예방교실 4기 / 대리 접수" + "어르신 대신 접수합니다. 번호는 문자 인증으로 꼭 확인해 주세요."
3. **전화번호** — 라벨 + [꼭 적어주세요] 배지 + 설명 "앱에 들어갈 때 쓰는 번호입니다. 번호만 있으면 들어갈 수 있어요." + 입력(높이 58~88px, radius 14px, placeholder `010-0000-0000`, inputmode numeric, maxlength 13). 조회 중에는 우측 18px 위치에 22px 스피너(보더 3px `#E4E1DA`, 상단 `#1F3C5D`, 0.8s linear).
4. **인증번호** (직원 모드 전용) — 라벨 + 설명 + 남은 시간 행(흰 카드, "남은 시간" + mm:ss tabular-nums, 60초 미만이면 `#A8241F`) + 입력(flex:1) + [확인] 버튼(min-width 96px, 인증 완료 시 `#17624A` + 라벨 "확인됨") + 재발송 텍스트 버튼.
5. **이름** — 라벨 + 배지 + 입력(placeholder "예) 홍길동", maxlength 20). 인증 미완료 시 `opacity:.45; pointer-events:none`.
6. **사시는 곳** — 라벨 + 배지 + 설명 + 고정값 행("인천광역시 남동구" + 우측 "고정") + 동 선택 버튼(선택 시 강조색 보더, 우측 › 셰브론). 인증 미완료 시 동일하게 비활성.
7. **동의** — 흰 카드(radius 16px, 보더 1px). 첫 행은 전체동의(배경 `#F7F6F2`, 체크박스 34px, 제목 17px/800 + 부제 14px). 이어 3행(체크박스 32px, 라벨 16px/600, `[필수]` 접두 + 우측 [보기] 버튼 58×44px). 행 전체가 탭 영역이며, 체크박스 버튼은 이벤트 전파를 끊어야 한다(그러지 않으면 토글이 두 번 발생해 상쇄됨 — 실제로 발생한 버그).
8. **하단 고정 제출 바** — position sticky bottom 0. [신청하기] 버튼(높이 58~88px, radius 16px) + 남은 항목 힌트("아직 남은 것: 전화번호 · 이름 …" / 모두 채우면 "다 적으셨어요. 눌러주세요.") + 실패 시 상태 메시지 + 보조 액션 버튼.
9. **아래 더 있어요 배지** — 첫 진입 시 제출 바 위에 pill 버튼(z-index 28). 스크롤 60px 넘으면 사라짐. 위치는 **고정 바의 실측 높이(`--ctah`)** 기준 — 고정값(124px)을 쓰면 글자 확대 시 바가 181px까지 자라 배지가 뒤로 숨는다.
10. **직원 모드 안내 카드** — `#FAF2E3` 배경, "어르신 대신 작성하는 화면입니다…" + 동의 영역 아래 "※ 위 동의는 어르신 본인이 직접 눌러주셔야 합니다. 대신 작성한 기록과 동의 시각이 함께 저장됩니다."
11. **대상자 바** (직원 모드) — sticky top 0. 좌측 8px 점(`#A9701A`) + "접수 중 · {번호}" + 우측 "오늘 N번째".

## Interactions & Behavior

### 전화번호 입력과 조회
- 숫자만 허용, 하이픈 자동 삽입(3-4-4). maxlength 13.
- 11자리가 완성되면 **자동 조회**. 프로토타입은 700ms 후 응답.
- 형식 불일치(010 시작 아님 등)는 11자리를 다 채운 뒤에만 안내. 입력 중에는 침묵.
- 번호를 고치면 조회 결과·인증 상태·메시지를 모두 초기화.

### 문자 인증 (직원 대리 접수 + 기존 회원 · 3기 참여자)
- 요구 조건: ① 기존 회원·3기 참여자 — **모드 무관** ② 직원 대리 접수 — 신규 번호 포함.
  신규 번호 + 어르신 모드만 무인증으로 통과한다.
- 조회 성공 직후 자동 발송. 6자리 숫자.
- 유효시간 5분. 만료 시 재발송 라벨이 "인증번호 다시 받기"로 전환되고 색이 `#A8241F`로.
- 재발송 쿨다운 30초. **대기 중에는 밑줄·포인터 없음**(회색 `#8A9299`), 누를 수 있을 때만 밑줄.
- 불일치는 [확인]을 누른 시점에만 판정하고 `(n/5번째)`로 남은 횟수 표시. **5회 실패 시 10분 잠금** — 확인·재발송을 함께 잠그고 보건소 문의로 연결한다. 6자리는 100만 가지뿐이라 제한이 없으면 인증이 형식적인 절차가 된다. 카운트의 정본은 서버다.
- 인증 완료 전에는 이름·동 입력 비활성.

### 제출
- 버튼은 **항상 활성**. 비활성으로 막지 않는다.
- 유효성 검사 순서: 번호 → 인증 → 이름 → 동 → 동의. 첫 오류에서 멈추고 (1) 해당 필드로 스크롤(offset 140px, smooth) (2) 필드 아래 메시지 (3) 토스트를 함께 띄운다.
- 이름 규칙: 2~20자, 한글·영문·공백만. 숫자·기호는 입력을 막지 않고 제출 시점에 반려.
- 필수 동의 누락 시 빠진 항목명을 나열("[필수] 이용약관 · 개인정보 수집·이용 에 동의해 주셔야 신청할 수 있어요").
- 제출 중 라벨 "신청하는 중이에요", 중복 클릭 차단. 프로토타입 지연 900ms.
- 실패(FS-02): "신청이 보내지지 않았어요. 적으신 내용은 그대로 있습니다. 계속 안 되면 보건소 담당자{전화번호}에게 문의해 주세요." + [다시 보내기]. 입력값 유지.
- 인증 만료 후 제출(FS-06): 인증만 재수행. 이름·동·동의는 유지.
- 오프라인(FX-04): 상단 띠 표시 + 제출 차단.
- 성공 시 상태값: 직원 접수 "보건소 직원 대리 접수 · 승인 요청" / 기존 회원 "기존 회원 연결 · 승인 요청" / 3기 "3기 이어서 참여 · 승인 요청" / 그 외 "승인 요청". **제출은 `PENDING`으로 저장되고 보건소 승인 후 교실 기능이 열립니다.**
- **제출 완료 시 직원 모드 자동 해제**, 접수 건수 +1. 완료 화면에서 [다음 분 신청받기]로 재진입.

### 애니메이션
스피너 회전 0.8s linear infinite가 유일. 스크롤은 smooth. prefers-reduced-motion에서 애니메이션 0.01ms + scroll-behavior auto.

5. 제출 버튼을 비활성화하지 않습니다. 눌렀을 때 무엇이 부족한지 알려주는 방식입니다.
