신청폼과 앱 회원가입이 이중으로 돌아 온보딩이 끊기는 문제를 없애기 위해, 신청 = 가입으로 합치고 관리자 승인 단계를 제거한다. 이 문서는 개발 착수에 필요한 화면 · 필드 · 분기 · 저장 항목만 정리한다. 문구 확정본과 예외 전체 목록은 별첨 문서를 따른다.

1. 범위와 전제

대상인천 남동구 거주 시니어. 현장 QR · 모집 문자로 진입
범위신청폼 1화면 + 결과 4화면 + 시트 3종. 앱 내부 화면은 범위 밖
인증전화번호가 로그인 ID. 비밀번호 없음. 문자 인증은 직원 대리 접수에서만
승인관리자 승인 없음. 제출 즉시 이용 가능
접근성본문 17px · 입력 19px · 터치 44px 이상, 본문 대비 4.5:1 이상, 글자 200% 확대 시 첫 입력칸 유지

4. SC-F-01 필드 정의

항목 필수 입력 · 검증 비고
휴대전화 번호필수숫자 입력, 하이픈 자동. 010 + 11자리만 통과. 11자리 완성 시 자동 조회로그인 ID. 오기입이 최대 리스크
인증번호조건부숫자 6자리. 유효 5분, 재발송 쿨다운 30초. [확인] 시점에만 판정직원 대리 접수에서만 노출
이름필수2~20자, 한글 · 영문 · 공백. 숫자 · 기호는 제출 시 반려기존 회원은 자동 채움 (수정 가능)
사시는 곳필수시 · 구 고정(인천 남동구). 행정동 20개 중 1개 선택모름 · 관외 탈출 경로 필요
동의필수 3
선택 1		이용약관 · 개인정보 수집이용 · 보건소 제3자 제공(필수) / 안내 문자(선택). 전체동의는 선택까지 포함항목별 [보기] 전문 시트 제공

제출 버튼은 항상 활성. 유효성은 번호 → 인증 → 이름 → 동 → 동의 순으로 검사하고, 첫 오류 항목으로 스크롤 + 해당 필드 아래 안내 + 토스트를 함께 띄운다. 버튼 아래에 남은 항목을 상시 표기한다.

7. 두 모드의 차이

구분 모드 A · 어르신 직접 모드 B · 직원 대리
식별네이비 헤더차콜 헤더 + 상단 모드 띠 + 대상자 바(번호 · 접수 건수)
문자 인증없음필수. 미인증 시 이름 · 동 입력 비활성
