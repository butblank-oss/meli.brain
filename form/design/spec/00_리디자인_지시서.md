# 클로드디자인 리디자인 지시서

맬리브레인 신청폼(인천 남동구 보건소 치매예방교실 4기) 개선안의 **시각 디자인을 다시 잡아주세요.**
구조·문구·분기는 이미 확정돼 있습니다. **바꿔야 하는 것은 보이는 것뿐입니다.**

---

## 그대로 두어야 하는 것 (구조·로직 확정)

1. **화면 구성** — 화면 5장 + 시트 2개. 추가·삭제·병합하지 않습니다. (`02_화면과_요소.md`)
2. **입력 순서** — 전화번호 → (인증번호) → 이름 → 사시는 곳 → 동의 → 제출. **순서를 바꾸지 않습니다.**
3. **문구** — `04_문구집.md`의 문장은 시니어 대상으로 다듬은 확정본입니다. 줄바꿈 위치까지 유지해 주세요.
4. **분기와 예외** — **90종**의 상태가 정의돼 있습니다. 새 상태를 만들거나 기존 상태를 합치지 않습니다. (`03_예외명세.md`)
5. **금지 사항** — `01_정책과_규칙.md`의 "절대 하면 안 되는 것" 12가지.

## 새로 잡아야 하는 것 (자유롭게)

- 색 팔레트 · 그러데이션 · 명암 (단, 대비 기준은 지켜야 함)
- 타이포 위계 · 자간 · 행간
- 카드 · 입력칸 · 버튼의 형태와 그림자
- 아이콘 · 일러스트 · 여백 리듬
- 완료 화면의 축하 표현, 상태 메시지의 시각 언어
- 기관 헤더(초록 그라데이션)의 표현 — 다만 "어느 기관의 폼인지"는 첫 화면에서 즉시 읽혀야 함

---

## 대상 사용자 — 이것이 모든 판단의 기준입니다

**치매예방교실에 참여하는 어르신(60~85세)** 입니다. 다음이 전제입니다.

| 전제 | 디자인에 주는 제약 |
|---|---|
| 노안 — 대부분 폰 글자 크기를 이미 키워둠 | 본문 17px 이상. 확대 시에도 레이아웃이 버텨야 함 |
| **"화면을 아래로 내린다"는 개념이 약함** | 주요 버튼을 문서 맨 아래에 두면 못 찾음 → **화면 붙박이** |
| 손떨림 · 건조한 손끝 | 터치 타겟 최소 44px, 주요 버튼 56~64px |
| 실패하면 다시 시도하지 않고 폼을 닫음 | 모든 오류에 다음 행동과 대안을 붙임 |
| 화면이 저절로 바뀌면 자기가 잘못 눌렀다고 생각함 | 자동 전환 금지 |
| 옆에서 보건소 직원이 도와주는 경우가 많음 | 직원이 어깨너머로 봐도 진행 상태가 읽혀야 함 |
| 현장이 밝은 실외(부스·복지관)일 수 있음 | 저대비 회색 글씨 금지 |

## 바로 붙여넣을 프롬프트

```
첨부한 index.html은 인천 남동구 보건소 치매예방교실 신청폼 프로토타입입니다.
60~85세 어르신이 현장에서 QR로 접속해 쓰는 화면입니다.

이 HTML의 시각 디자인만 다시 잡아주세요. 구조·문구·입력 순서·분기는 확정본이라
바꾸지 말고, 색·타이포·형태·여백·아이콘만 새로 잡아주세요.

반드시 지켜야 할 것:
1. 본문 17px 이상, 입력값 19px 이상, 터치 타겟 44px 이상, 주요 버튼 56~64px
2. 제출 버튼은 화면 붙박이(sticky bottom). 문서 맨 아래에 두지 마세요.
   어르신은 스크롤 개념이 약해서 다 적고도 버튼을 못 찾습니다
3. 글자를 200%로 키워도 가로 스크롤이 생기지 않고 첫 입력칸이 첫 화면에 보여야 합니다.
   헤더·도움말은 clamp()로 상한을 걸고, 라벨·입력·버튼은 크게 늘어나게 하세요
4. 상태(성공/오류/경고)를 색으로만 구분하지 마세요. 아이콘 + 배경 + 문구를 함께 쓰세요
5. 본문 대비 4.5:1 이상. 밝은 실외에서 봅니다
6. 조상 요소에 overflow:hidden을 쓰지 마세요. sticky가 죽습니다
7. 미체크 체크박스는 빈 네모로. 회색 체크 표시는 이미 체크된 것처럼 보입니다
8. 애니메이션은 prefers-reduced-motion에서 꺼지게 하세요

같이 첨부한 문서:
- 01_정책과_규칙.md   무엇을 바꾸면 안 되는지
- 02_화면과_요소.md   화면 5장 + 시트 2개의 요소 목록
- 03_예외명세.md      화면이 가져야 하는 모든 상태 (90종)
- 04_문구집.md        확정된 문구 (줄바꿈까지 유지)
- 05_디자인토큰_접근성.md  현재 토큰과 지켜야 할 기준
```
