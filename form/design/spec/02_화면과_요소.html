SC-F-01 신청폼 — 요소

코드 요소 규칙
S1-01 앱바 로고 16px 800. 링크가 아님 (이탈 방지)
S1-02 글자 크기 버튼 가＋ 42px 터치. 4단계 순환. 전환 시 현재 단계를 토스트로 고지
S1-03 오프라인 띠 오프라인일 때만. 제출 차단
S1-04 직원 모드 배너 직원 모드에서만. 진한 배경으로 일반 화면과 확실히 구분 + 나가기
S1-05 기관 배지 어느 기관의 폼인지 첫 화면에서 확정
S1-06 제목 22px 800 · 2줄. 직원 모드에서는 "대리 접수"로
S1-07 부제 관외 조건과 자동 승인을 입력 전에 미리 알림
S1-08 직원 안내 박스 직원 모드에서만. 주황 계열
S1-09 복구 배너 임시저장 복원 시. 직원 모드에서는 안 뜸
S1-10 전화번호 라벨 17px 700 + 꼭 적어주세요 배지 (별표 금지)
S1-11 전화번호 도움말 앱 가입이 없어졌다는 사실을 여기서 알림
S1-12 전화번호 입력 높이 60px · 19px · inputmode=numeric · autocomplete=tel · 하이픈 자동 · 11자리 완성 시 자동 조회
S1-13 조회 스피너 입력칸 오른쪽 안쪽
S1-14 전화번호 상태 아이콘+배경+테두리 · role=status aria-live=polite
S1-15 인증번호 블록 기존 회원·직원 모드에서만 노출
S1-16 유효시간 표시 남은 시간 4:32. 1분 미만 빨강. tabular-nums로 자릿수 흔들림 방지
S1-17 인증번호 입력 autocomplete=one-time-code (iOS 자동 채움) · 숫자 6자리
S1-18 확인 버튼 6자리를 채워야 활성. 통과 시 초록 확인됨 + 입력칸 읽기 전용
S1-19 재발송 보조 버튼으로 하단 배치 (오조작 감소). 만료 시 인증번호 다시 받기로 강조 전환
S1-20 이름 입력 2~20자 · 제출 시 검사 · autocomplete=name
S1-21 주소 고정 배지 인천광역시 남동구 + 자물쇠. 입력 불가
S1-22 동 선택 버튼 60px · 시트 호출 · aria-haspopup=dialog
S1-23 모두 동의 34px 체크박스. 선택 항목까지 켜진다는 부제 필수
S1-24 동의 항목 ×4 각 항목 보기 버튼(44px)
S1-25 대리 동의 주의 직원 모드에서만
S1-26 제출 버튼 (고정) sticky bottom:0 · 높이 clamp(58, 64×배율, 88) · 항상 활성
S1-27 남은 항목 안내 버튼 바로 아래. 실시간 갱신
S1-28 직원 진입 링크 폼 맨 아래 14px 회색. 어르신 눈에 먼저 띄지 않게
S1-29 스크롤 안내 아래에 더 있어요 ▾. 맨 위 + 아래에 내용이 남았을 때만. 한 번 내리면 감춤. 위치는 고정 바 높이를 측정한 --ctah 기준 — 고정값을 쓰면 글자 확대 시 바 뒤로 숨음
S1-30 대상자 바 (직원 모드) sticky top:0. 좌측 점 + 접수 중 · {번호} + 우측 오늘 N번째. 직원이 지금 누구를 접수 중인지 확인

SC-F-02 신청 완료 — 요소

코드 요소 규칙
S2-01 완료 마크 76px · role=img aria-label="완료"
S2-02 헤딩 "승인 대기"가 아니라 끝났다고 단언 — 자동 승인의 핵심 메시지
S2-03 리드 다음 할 일을 한 문장으로
S2-04 신청 내역 전화번호는 010-****-5678 마스킹 (현장 어깨너머 노출 방지)
S2-05 상태값 경로별 4종 (신규 / 기존 회원 연결 / 3기 이어서 / 직원 대리)
S2-06 설치 3단계 색 지칭 금지. 로그인에 쓸 값이 방금 적은 번호임을 명시
S2-07 설치 버튼 UA 판별로 본인 기기를 크게(62px), 반대 기기는 보조(52px). 판별 실패 시 동일 크기 병렬
S2-08 QR 132px. "다른 휴대폰으로 찍어도 됩니다" — 보조 수단
S2-09 문자 안내 지금 설치를 못 해도 끊기지 않는다는 안전망. 직원 모드에서 문구 다름
S2-10 보건소 전화 21px 800. 모든 결과 화면 공통
S2-11 복귀 버튼 처음으로 돌아가기 / 직원 모드는 다음 분 신청받기
S2-12 직원 모드 해제 제출이 끝나면 직원 모드를 자동으로 해제하고 접수 건수를 +1. 공용 기기가 직원 모드로 방치되는 것을 막음. [다음 분 신청받기]로 재진입

화면에 없는 것 — 의도적으로 뺀 것

  • 단계 분할(멀티스텝) — 되돌아가기가 어렵고 현재 위치를 계속 추적해야 함. 항목이 4개뿐
  • 주소 검색(우편번호) — 검색어 입력은 시니어에게 가장 높은 허들
  • 생년월일·성별 — 현행 폼에 없고 자동 승인 판정에 쓰이지 않음
  • 본인인증(PASS·아이핀) — 통신사 인증 앱 설치는 사실상 이탈 지점. SMS 6자리로 대체
