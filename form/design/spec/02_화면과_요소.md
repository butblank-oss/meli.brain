# 02. 화면과 요소

화면 **5장** + 시트 **2개**. 추가·삭제·병합하지 않습니다.

```
                    [진입 · QR / 문자 링크]
                              │
              ┌───────────────┴───────────────┐
    FX-01 기간 아님                      모집 기간 중
              │                               │
      [SC-F-05 모집마감]              [SC-F-01 신청폼]
                                              │
        ┌───────────────┬─────────────────────┼──────────────┐
   FD-02 관외      FE-06 중복          FS-07 제출 성공    시트 2개
        │               │                     │        (동 선택 · 약관)
 [SC-F-04 관외]  [SC-F-03 이미신청]   [SC-F-02 완료]
        │               │                     │
        └───────────────┴─────────→ [맬리브레인 앱 · 전화번호 로그인]
```

| 코드 | 화면 | 목적 | 진입 | 나가는 길 |
|---|---|---|---|---|
| SC-F-01 | 신청폼 | 번호·이름·동·동의를 받고 회원 생성까지 | QR / 안내 문자 | 제출 성공 → SC-F-02 |
| SC-F-02 | 신청 완료 | 승인 완료 통보 + 그 자리 설치 | 제출 성공 | 스토어 · QR · 처음으로 |
| SC-F-03 | 이미 신청함 | 중복 접수를 막고 설치만 안내 | 조회 중복 · 제출 경합 | 스토어 · 번호 다시 넣기 |
| SC-F-04 | 남동구 거주 아님 | 막다른 길을 없애고 대안 제시 | 동 시트에서 관외 선언 | 앱 일반 이용 · 다시 골라보기 |
| SC-F-05 | 모집 기간 아님·마감 | 폼을 열지 않고 알림 예약만 | 기간 외 · 정원 마감 | 알림 신청 · 보건소 전화 |
| SH-01 | 시트 · 동 선택 | 관내 20개 동 + 탈출구 2개 | 거주지 선택 버튼 | 선택 · 모름 · 관외 |
| SH-02 | 시트 · 약관 전문 | 동의 항목 4종의 본문 | 동의 항목의 "보기" | 동의 · 닫기 |
| SH-03 | 시트 · 3기 참여자 확인 | 자동 채움 전에 본인 확인 | 조회 결과 = 이전 기수 참여자 | 이어서 신청 · 번호 다시 넣기 |

| S1-19 | 재발송 | **보조 버튼으로 하단 배치** (오조작 감소). 만료 시 `인증번호 다시 받기`로 강조 전환 |

| S1-22 | 동 선택 버튼 | 60px · 시트 호출 · `aria-haspopup=dialog` |
| S1-23 | 모두 동의 | 34px 체크박스. **선택 항목까지 켜진다는 부제 필수** |
| S1-24 | 동의 항목 ×4 | 각 항목 `보기` 버튼(44px) |
| S1-25 | 대리 동의 주의 | 직원 모드에서만 |
| S1-26 | **제출 버튼 (고정)** | `sticky bottom:0` · 높이 `clamp(58, 64×배율, 88)` · **항상 활성** |
| S1-27 | 남은 항목 안내 | 버튼 바로 아래. 실시간 갱신 |
| S1-28 | 직원 진입 링크 | 폼 **맨 아래** 14px 회색. 어르신 눈에 먼저 띄지 않게 |
| S1-29 | 스크롤 안내 | `아래에 더 있어요 ▾`. 맨 위 + 아래에 내용이 남았을 때만. 한 번 내리면 감춤. **위치는 고정 바 높이를 측정한 `--ctah` 기준** — 고정값을 쓰면 글자 확대 시 바 뒤로 숨음 |
| S1-30 | 대상자 바 (직원 모드) | `sticky top:0`. 좌측 점 + `접수 중 · {번호}` + 우측 `오늘 N번째`. 직원이 지금 누구를 접수 중인지 확인 |

## 화면에 없는 것 — 의도적으로 뺀 것

- **단계 분할(멀티스텝)** — 되돌아가기가 어렵고 현재 위치를 계속 추적해야 함. 항목이 4개뿐
- **주소 검색(우편번호)** — 검색어 입력은 시니어에게 가장 높은 허들
- **생년월일·성별** — 현행 폼에 없고 자동 승인 판정에 쓰이지 않음
- **본인인증(PASS·아이핀)** — 통신사 인증 앱 설치는 사실상 이탈 지점. SMS 6자리로 대체
