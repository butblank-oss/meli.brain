# 04. 문구집 — 확정본

시니어 대상으로 다듬은 확정 문구입니다. **줄바꿈 위치까지 유지**해 주세요.
`{}`는 값이 들어가는 자리, `[]`는 버튼 라벨입니다.

## 문구 원칙

- 한 문장 40자 이내, 한 문장 한 가지. "~하시고 ~하시면"으로 잇지 않음
- 명사 나열 금지 — "동 선택" ✗ → "어느 동에 사세요?" ✓
- 한자어·영문 약어 금지 — "인증" 대신 "본인이 맞는지 확인", "SMS" 대신 "문자"
- 색으로 지칭하지 않음 — "파란 버튼" ✗ → "설치 버튼" ✓
- 실패를 사용자 탓으로 돌리지 않음 — "잘못 입력하셨습니다" ✗ → "어르신 잘못이 아닙니다" ✓
- 오류만 말하고 끝내지 않음. **다음에 할 일을 항상 한 문장으로** 붙임

### 전화번호
```
휴대전화 번호  [꼭 적어주세요]
앱에 들어갈 때 쓰는 번호입니다. 번호만 있으면 들어갈 수 있어요.
placeholder: 010-0000-0000
```
| 상태 | 문구 |
|---|---|
| 조회 중 | 확인하고 있어요. 잠시만요. |
| 신규 | 처음 오셨네요. 아래 두 가지만 적어주시면 됩니다. |
| 기존 회원 | 이미 맬리브레인을 쓰고 계세요. 본인이 맞는지 문자로 한 번만 확인할게요. |
| 이전 기수 | 3기에 참여하셨던 분이네요. 본인이 맞는지 문자로 한 번만 확인할게요. |
| 인증 후(기존) | **{이름}** 님이시네요. 적어두신 내용을 채워뒀어요. 바뀐 게 있으면 고쳐주세요. |
| 인증 후(3기) | 3기에 참여하셨던 **{이름}** 님이시네요. 적어두신 내용을 채워뒀어요. 바뀐 게 있으면 고쳐주세요. |
| 형식 오류 | 번호를 다시 봐주세요. **010**으로 시작하는 11자리입니다. |
| 중복 | 이 번호로 **이미 신청**하셨어요. 다시 신청하지 않으셔도 됩니다. `[신청한 내용 보기]` |
| 이용 제한 | 이 번호로는 신청이 어렵습니다. 남동구 보건소(032-000-0000)로 전화 주시면 확인해 드릴게요. |
| 과다 조회 | 확인을 너무 여러 번 하셨어요. **1분 뒤에** 다시 해주세요. |
| 조회 실패 | 지금 확인이 안 되고 있어요. 어르신 잘못이 아닙니다. `[다시 해보기]` |

### 동의
```
동의해 주세요

☐ 아래 내용에 모두 동의합니다
   세 가지 모두 동의하셔야 신청할 수 있어요
☐ [필수] 맬리브레인 서비스 이용약관              [보기]
☐ [필수] 개인정보 수집·이용 동의                 [보기]

```

**교정 사유**
- 띄어쓰기 — `잠시후` → `잠시 후`, `안되는` → `안 되는`, `문의주세요` → `문의해 주세요`
- FS-02에서 **"적으신 내용은 그대로 있습니다"를 빼지 마세요.** 장식이 아니라 재시도율을 좌우하는 문장입니다.
  어르신은 실패 화면에서 "처음부터 다시 써야 하나" 싶으면 그 자리에서 닫습니다.
- 한 문장 40자 이내 · 한 문장 한 가지 — 원인, 상태, 다음 행동을 한 문장에 몰지 않습니다.
