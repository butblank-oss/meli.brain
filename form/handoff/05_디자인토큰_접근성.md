# 05. 디자인 토큰 · 접근성 기준

현재 프로토타입의 값입니다. **색·형태는 자유롭게 바꾸되, 아래 "지켜야 할 기준"은 유지**해 주세요.

## 현재 토큰 (참고용 — 바꿔도 됨)

```css
/* 브랜드 */
--g:      #0E7A52;   /* 주 초록 — 버튼·강조 */
--g-d:    #0A6B47;   /* 진한 초록 — 텍스트 강조 */
--g-l:    rgba(16,84,62,.09);

/* 글자 */
--ink:    #191F28;   /* 본문 */
--ink2:   #4E5968;   /* 보조 */
--ink3:   #8B95A1;   /* 도움말 — 여기까지가 대비 하한 */

/* 면 */
--line:   #DDE2E7;
--bg:     #F7F9FA;
--wt:     #FFFFFF;

/* 상태 */
--err:    #D6353A;  --err-bg:  #FFF5F5;  --err-line:  #F3C2C4;
--warn:   #9A5B00;  --warn-bg: #FFF6E5;  --warn-line: #F0D9A8;
--info:   #2F6FA8;

/* 글자 확대 배율 — 0.0 ~ 1.6 */
--fs: 1;
```

서체: `Pretendard Variable` (한글 숫자 정렬이 좋고 굵기 단계가 촘촘함).
기관 헤더: `linear-gradient(135deg, #0E7A52, #0A5D3E)`

## 크기 (현재)

| 용도 | 값 |
|---|---|
| 본문 | 17px |
| 입력값 · 동 선택 버튼 | 19px |
| 라벨 | 17px / 700 |
| 도움말 · 캡션 | 13px |
| 제목 | 22px / 800 / 자간 -0.035em |
| 입력칸 높이 | 60px |
| 주요 버튼 | 64px |
| 보조 버튼 | 56px |
| 체크박스 | 34px (행 전체 터치) |
| 약관 `보기` 버튼 | 44px |
| 라운드 | 입력 12px · 카드 14px · 시트 22px · 알약 999px |
| 폼 좌우 여백 | 20px |
| 필드 간 간격 | 24px |

---

## 지켜야 할 기준

### 1. 크기 하한

| 항목 | 하한 | 이유 |
|---|---|---|
| 본문 | **17px** | 노안 기준. 일반 서비스의 14~15px은 읽히지 않음 |
| 입력값 | **19px** | 자기가 뭘 쳤는지 확인할 수 있어야 오타를 스스로 잡음 |
| 터치 타겟 | **44px**, 주요 버튼 56~64px | 손떨림·건조한 손끝에서의 인식률 |
| 체크박스 | **34px** + 행 전체 터치 | WCAG 최소치(24px)로는 부족 |

### 2. 대비

- 본문 **4.5:1** 이상, 큰 글씨 **3:1** 이상 (WCAG 2.2 AA)
- **현장이 밝은 실외**(부스·복지관)일 수 있음. 저대비 회색 글씨 금지
- `--ink3`(#8B95A1)가 흰 배경에서 대비 하한. 그보다 옅은 회색은 쓰지 않음

### 3. 글자 확대 정책 ★ 가장 자주 깨지는 부분

어르신은 **폰 자체 글자 크기를 이미 키워둔 상태**로 들어옵니다.
전부 같은 비율로 키우면 헤더만 한 화면을 다 먹고 첫 입력칸이 화면 밖으로 밀려납니다.

| 구분 | 대상 | 처리 |
|---|---|---|
| **크게 늘림** | 라벨 · 입력값 · 버튼 · 오류 메시지 | 배율을 거의 그대로 반영 |
| **상한을 검** | 로고 · 제목 · 부제 · 도움말 · 캡션 | `clamp()`로 최대치 고정 |

```css
/* 예시 */
.org h2 { font-size: clamp(21px, calc(22px * var(--fs)), 27px); }   /* 제목 — 상한 */
.help   { font-size: clamp(13px, calc(13px * var(--fs)), 17px); }   /* 도움말 — 상한 */
input   { font-size: clamp(19px, calc(19px * var(--fs)), 26px); }   /* 입력값 — 크게 */
.btn    { font-size: clamp(19px, calc(20px * var(--fs)), 27px);
          min-height: clamp(58px, calc(64px * var(--fs)), 88px); }  /* 버튼 — 상한 88px */
```

검증: **360×640 화면 + 글자 200%** 에서
- 가로 스크롤이 생기지 않을 것
- 첫 입력칸이 첫 화면에 보일 것
- 고정 버튼이 화면 높이의 **30%를 넘지 않을** 것

### 4. 고정 버튼 (sticky)

```css
.cta {
  position: sticky;
  bottom: 0;
  z-index: 26;
  padding: 12px 16px calc(14px + env(safe-area-inset-bottom));
  background: rgba(247,249,250,.97);
  backdrop-filter: blur(10px);
  border-top: 1px solid var(--line);
  box-shadow: 0 -6px 20px rgba(18,32,26,.10);
}
@media (max-height: 560px) { /* 가로 모드·확대 시 여백 축소 */ }
```

- **조상 요소에 `overflow:hidden`을 쓰지 마세요.** sticky가 조용히 죽습니다.
- 입력칸에 포커스가 가면 고정 버튼 높이를 계산해, 가려질 경우 화면 가운데로 끌어옵니다.
- 아직 못 본 내용이 있으면 버튼 위에 `아래에 더 있어요 ▾` 알약을 띄우고, 한 번 내리면 감춥니다.

### 5. 상태 표현 — 색 + 아이콘 + 문구 3중

```
성공  ✓  초록 배경 + 초록 테두리 + 진한 초록 글씨
오류  !  연빨강 배경 + 빨강 테두리 + 진한 빨강 글씨
경고  !  연주황 배경 + 주황 테두리 + 진한 주황 글씨
```
- 색만으로 구분하지 않습니다. **흑백으로 봤을 때도 구분**돼야 합니다.
- 상태 메시지는 해당 필드 **바로 아래**. 화면 상단 요약 배너는 쓰지 않습니다.

### 6. 체크박스

- 미체크 = **빈 네모** (회색 체크 표시 금지 — 이미 체크된 것처럼 보임)
- 체크 = 브랜드 색 바탕 + 흰 체크
- 행 전체가 터치 영역

### 7. 접근성 마크업

```html
<!-- 상태 메시지 -->
<p role="status" aria-live="polite">…</p>

<!-- 체크박스 -->
<button role="checkbox" aria-checked="false" aria-labelledby="c1t">…</button>

<!-- 시트 -->
<div role="dialog" aria-modal="true" aria-labelledby="…">…</div>
<!-- 열 때 첫 조작 대상으로 포커스, 닫을 때 연 버튼으로 복귀, ESC·뒤로가기 지원 -->

<!-- 입력 -->
<input type="tel" inputmode="numeric" autocomplete="tel">
<input type="text" inputmode="numeric" autocomplete="one-time-code">
<input type="text" autocomplete="name">
```
- **비활성(disabled) 버튼을 쓰지 않습니다** — 스크린리더가 읽지 않고 아무 피드백도 주지 않습니다.
- 포커스 링은 반드시 보이게: `outline: 3px solid rgba(brand,.32); outline-offset: 1px`
- `@media (prefers-reduced-motion: reduce)` 에서 애니메이션을 끕니다.
- 숫자 카운트다운은 `font-variant-numeric: tabular-nums` (자릿수 흔들림 방지)

### 8. 모션

- 스크롤 이동은 `behavior:"smooth"`, 그 외 전환은 거의 쓰지 않습니다
- **화면이 저절로 바뀌는 연출 금지** — 시니어는 오작동으로 인식합니다
- 스피너 외의 로딩 연출(스켈레톤 등)은 쓰지 않습니다 — 내용이 있는 것으로 오해합니다
