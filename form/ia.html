1이 문서가 다루는 것

인천 남동구 보건소 치매예방교실 신청폼의 정보 구조와 화면 설계입니다. 화면이 몇 개이고, 무엇이 어떤 순서로 나오고, 어떤 조건에서 어디로 갈라지는지를 정합니다.

예외 상황 66종의 처리 방법은 이 문서에 없습니다 — 예외명세에 따로 있습니다. 실제 화면 동작은 프로토타입이 기준이며, 이 문서와 어긋나면 프로토타입을 따릅니다.

화면에 없는 것 — 의도적으로 뺀 것들

단계 분할(멀티스텝) 없음 — 1단계씩 넘기는 구조는 되돌아가기가 어렵고, 어르신은 "지금 몇 단계인지"를 계속 추적해야 합니다. 항목이 4개뿐이라 한 화면 스크롤이 부담이 적습니다.

주소 검색(우편번호) 없음 — 검색어 입력은 시니어에게 가장 높은 허들입니다. 동 20개 버튼으로 대체했습니다.

생년월일·성별 없음 — 현행 폼에 없고, 자동 승인 판정에 쓰이지 않습니다. 필요하면 앱 온보딩에서 받습니다.

본인인증(PASS·아이핀) 없음 — 시니어에게 통신사 인증 앱 설치는 사실상 이탈 지점입니다. SMS 6자리로 대체.

버튼 위치와 스크롤

어르신은 "화면을 아래로 내린다"는 개념 자체가 약합니다. 그래서 버튼 위치는 취향 문제가 아닙니다.

· 주요 버튼은 문서 맨 아래에 두지 않습니다. 제출 버튼은 position:sticky; bottom:0으로 화면에 붙박여 스크롤 위치와 무관하게 항상 보입니다. "다 적었는데 버튼이 없다"가 실제 이탈 지점입니다.

· 고정 버튼은 크기 상한이 있어야 합니다. 글자를 200%로 키운 기기에서 버튼이 그대로 늘어나면 화면 절반을 먹습니다. clamp(58px, 64px×배율, 88px)로 묶고, 화면 높이 560px 미만에서는 여백을 더 줄입니다.

· 고정 버튼이 입력칸을 가리면 안 됩니다. 입력칸에 포커스가 가면 버튼 높이를 계산해 가려질 경우 화면 가운데로 끌어옵니다.

· 아직 못 본 내용이 있으면 알려줍니다. 맨 위에 있고 아래에 내용이 더 있을 때만 아래에 더 있어요 ▾를 띄우고, 한 번 내리면 감춥니다. 계속 떠 있으면 내용을 가립니다.

· 조상 요소에 overflow:hidden을 쓰지 않습니다. 붙박이가 조용히 죽습니다 (v0.2 구현 중 실제로 발생 — 시각적으로 티가 안 나서 놓치기 쉽습니다).

중대 — 상당수가 막히던 것

코드문제조치
B-01첫 화면에 탭 2개. 어르신이 "직접 신청"과 "도움받아 신청" 중 무엇을 눌러야 하는지 판단해야 함. QR을 찍은 시점에 이미 직원이 옆에 있는데 본인이 누르면 직접 신청이고, 직원이 대신 누르면… 기준이 모호해 첫 화면에서 멈춥니다 기본은 신청폼 하나만. 직원 모드는 폼 맨 아래 "보건소 직원이신가요?" 링크로만 진입하고, 들어가면 상단에 진한 배너와 나가기가 붙습니다
B-02인증번호 유효시간 5분인데 화면에는 재발송 쿨다운 30초만 보임. 30초 안에 넣어야 하는 줄 알고 당황함 (실제 오해 사례 확인) 남은 유효시간을 4:32 카운트다운으로 항상 노출하고, 1분 미만이면 빨강으로 바뀝니다. 재발송은 "문자가 안 왔어요? 다시 보내기 (30초 뒤부터)"로 문장을 분리
B-03중복 신청 시 1.2초 뒤 화면이 저절로 바뀜 자동 전환 제거. 안내 메시지 안의 신청한 내용 보기 버튼을 눌러야 이동합니다. 시니어는 화면이 저절로 바뀌면 자기가 뭘 잘못 눌렀다고 생각합니다
B-04제출 버튼이 비활성이라 왜 못 누르는지 알 수 없음 버튼을 항상 살려두고, 누르면 첫 번째로 빠진 항목까지 스크롤·포커스하고 그 자리에 이유를 띄웁니다. 버튼 아래에는 "아직 남은 것: 이름 · 동의"를 계속 보여줍니다. (비활성 버튼은 스크린리더가 읽지 않고, 어르신에게는 아무 반응 없는 버튼으로 보입니다)
B-05입력 중 이탈하면 전부 사라짐. 어르신은 입력 중 전화를 자주 받습니다 입력값을 브라우저에 24시간 임시 저장하고 복귀 시 복원 배너를 띄웁니다. 직원 모드(공용 기기)에서는 저장하지 않고 기존 저장분도 지웁니다
B-07제출 버튼이 문서 맨 아래에 있어 스크롤해야만 보임. 어르신은 "아래로 내려야 한다"는 인식 자체가 약해서, 다 적고도 버튼을 못 찾고 멈춥니다 제출 버튼을 화면 붙박이(sticky)로 바꿔 스크롤 위치와 상관없이 항상 보이게 했습니다. 아직 못 본 내용이 남아 있으면 버튼 위에 아래에 더 있어요 ▾ 알약 버튼을 띄우고, 누르면 한 화면만큼 내려갑니다. 한 번 내리면 사라집니다 (붙박이 버튼이 역할을 넘겨받으므로)
B-08모든 글자를 같은 비율로 확대. 폰 자체 글자 크기를 이미 키워둔 분이 들어오면 기관 헤더만으로 첫 화면이 다 차고 첫 입력칸이 화면 밖으로 밀려납니다 역할별로 확대 정책을 나눴습니다. 읽고 조작하는 것(라벨·입력값·버튼·오류)은 크게 늘리고, 맥락만 주는 것(로고·제목·부제·도움말)은 clamp()로 상한을 겁니다. 고정 버튼도 최대 88px에서 멈춰 화면을 삼키지 않습니다
B-06완료 화면에서 "아이폰 / 안드로이드"를 어르신이 골라야 함 User-Agent로 기기를 판별해 본인 기기 버튼만 크게 띄우고, 반대 기기는 작은 보조 버튼으로 내립니다. 판별 실패 시에만 둘을 같은 크기로 병렬 노출
