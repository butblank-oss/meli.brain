전화번호 입력 후 조회에서 "처음 오셨네요"로 안내하고, 이름·동을 직접 입력받습니다.

시니어 대상이라 OS 폰트 확대(최대 200%)에서도 레이아웃이 깨지지 않아야 합니다.

· 자동승인 — 이 폼은 남동구 보건소 전용이므로 제출 즉시 승인 상태로 생성합니다. (보건소 확인 대기 항목)

· 앱 회원가입 제거 — 제출로 회원까지 생성하고, 앱에서는 전화번호 로그인만 합니다.

· 관외 차단 — 주소는 "인천 남동구" 고정 + 관내 20개 행정동 버튼 선택. 자유 입력 불가.

· 대리 신청 — 직원이 대신 쓰는 경우 SMS 인증번호로 본인 확인하고, 동의는 어르신이 직접 누릅니다.

· 조회 결과의 이름은 홍*동으로 마스킹해서 본인 확인만 시킴 (번호만 알면 타인 정보가 노출되지 않게)
· 인증번호 6자리 · 유효 5분 · 재발송 30초 쿨다운 · 5회 실패 시 10분 잠금
· 필수 3 / 선택 1 분리 동의 (개인정보보호법 §22 ④)
· 대리 작성 건은 작성경로=직원대리 · 직원 식별자 · 동의 시각을 함께 저장
· 완료 화면의 전화번호는 뒷 4자리만 노출 (현장 화면 어깨너머 노출 방지)
