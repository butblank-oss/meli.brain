현장 장애 대처 — 치매예방교실 접수

대상 보건소 현장에서 어르신 접수를 진행하는 직원 버전 개발본 2026-09-29 기준 (자동 승인 · 제출 = 참여 확정) 원칙 어르신을 기다리게 하지 않는다. 막히면 종이로 받고 나중에 넣는다.

0. 시작하기 전 (현장 도착 후 10분)

접수를 시작하기 전에 직원 본인 폰으로 한 번 돌려봅니다. 어르신 앞에서 처음 열지 않습니다.

확인 안 되면
1 폼 주소가 열린다 네트워크·주소 확인 → §1
2 직원 모드 로그인이 된다 §2 — 로그인이 안 되면 현장 접수 전면 중단
3 본인 번호로 시험 접수 → 문자가 온다 §3
4 시험 접수를 되돌리기로 지웠다 안 지우면 직원이 참여자로 남습니다
5 보건소 와이파이 대신 직원 폰 데이터로도 열린다 와이파이가 죽어도 계속할 수 있습니다

챙길 것 — 보조배터리, 종이 접수지·동의서 묶음(§8), 보건소 대표번호, 개발 담당 연락처.

1. 폼이 안 열린다

증상 먼저 그래도 안 되면
흰 화면 / 계속 도는 중 새로고침 1회 다른 브라우저(크롬↔사파리)
"연결할 수 없음" 와이파이 끄고 데이터로 다른 직원 폰
주소를 눌렀는데 엉뚱한 곳 지난 기수 링크일 수 있음 — 주소의 기수 확인 올바른 링크 재전송
글자가 깨지거나 버튼이 안 보임 브라우저 확대 100%로 다른 폰

5분 안에 안 되면 §8 종이 접수로 전환합니다. 어르신을 세워두고 고치지 않습니다.

2. 직원 로그인이 안 된다

  1. 번호를 정확히 넣었는지 — 본인 번호여야 합니다 (케어센터와 같은 계정).
  2. 인증번호 문자가 오는지 — 안 오면 §3.
  3. 등록 안 된 직원이면 권한 없음이 뜹니다 → 담당자에게 계정 등록 요청.

로그인이 안 되면 대리 접수를 할 수 없습니다. 두 가지만 가능합니다.

  • 어르신이 직접 자기 폰으로 링크를 받아 신청 (이것도 즉시 확정됩니다)
  • 종이 접수 (§8)

3. 문자가 안 온다

가장 흔한 문제입니다. 순서대로 확인합니다.

순서 확인 조치
1 번호를 잘못 적지 않았나 접수 내역에서 번호를 어르신께 소리 내어 읽어 확인
2 3분이 지났나 3분까지는 기다립니다. 연타하지 않습니다
3 폰이 꺼져 있거나 신호가 없나 켜고 신호 확인
4 스팸 차단 설정 설정 → 메시지 → 차단 목록 확인
5 저장 공간 가득 오래된 문자 삭제

문자가 끝내 안 와도 접수는 유효합니다. 어르신께 이렇게 안내합니다.

"신청은 다 됐습니다. 문자가 늦을 수 있으니 앱스토어에서 '맬리브레인'을 직접 찾아 설치하시고, 방금 적은 전화번호로 들어가시면 됩니다."

번호가 틀렸던 경우에는 §5로 되돌린 뒤 다시 접수합니다.

4. 제출이 안 된다 / 눌러도 반응이 없다

증상 조치
버튼을 눌러도 아무 일이 없다 빠진 항목이 있습니다. 버튼 아래 '아직 남은 것'을 확인
이름·동·성별 칸이 눌리지 않는다 번호를 먼저 넣어야 풀립니다. 기존 회원이면 문자 인증까지
"다시 시도" 안내가 뜬다 네트워크 문제. 입력값은 그대로 있습니다. 한 번만 더 누름
눌렀는데 멈춰 있다 연타하지 않습니다. 10초 기다린 뒤 §6으로 중복 확인

절대 하지 말 것 — 반응이 없다고 [신청하기]를 여러 번 누르기. 두 건이 들어가면 정원과 명단이 틀어집니다.

5. 잘못 등록했다

자동 승인이라 제출 즉시 확정됩니다. 되돌리기가 유일한 수습 경로입니다.

바로 알아챈 경우

  1. 직원 모드 → [오늘 내가 처리] 목록을 연다
  2. 해당 건을 찾아 [되돌리기]를 두 번 누른다
  3. 승인 대기로 돌아가고 교실 배정·상담 채널도 함께 걷힙니다
  4. 올바른 정보로 다시 접수합니다

나중에 알아챈 경우 (다음 날 등)

[오늘 내가 처리]에는 당일 건만 보입니다. 케어센터 신청자 화면에서 찾아 처리하거나 담당자에게 요청합니다.

번호를 잘못 적어 남의 번호로 승인된 경우 ⚠

가장 위험합니다. 그 번호의 실제 주인이 앱을 깔고 로그인하면 자동으로 참여자가 됩니다.

  1. 즉시 되돌리기
  2. 이미 문자가 나갔으면 그 번호로 전화해 잘못 발송됐다고 안내
  3. 담당자에게 보고 — 개인정보 오발송 건으로 기록이 필요할 수 있습니다

예방이 전부입니다. 접수 전에 어르신 폰 화면의 번호를 직접 보고 입력하세요. 어르신이 불러주는 번호를 받아적지 마세요. 가장 흔한 사고 원인입니다.

6. 중복으로 넣은 것 같다

  1. 같은 번호를 번호칸에 다시 넣어봅니다 → 이미 신청 안내가 뜨면 한 건만 들어간 것입니다
  2. [오늘 내가 처리] 목록에서 같은 이름이 두 번 보이면 하나를 되돌립니다
  3. 어느 쪽을 지울지 모르면 나중 것을 지웁니다

7. 앱에서 교실이 안 보인다

어르신이 앱을 깔았는데 교실 화면이 아니라 체험 화면이 나오는 경우입니다.

확인 조치
신청한 번호로 로그인했나 다른 번호로 가입했으면 신청한 번호로 다시 로그인
신청이 되어 있나 폼에 번호를 넣어 확인. 없으면 지금 접수
앱을 먼저 깔고 가입한 경우 앱만으로는 교실에 못 들어갑니다. 직원이 폼에서 그 번호로 접수해야 합니다
방금 승인됐는데 화면이 그대로 앱을 완전히 껐다 켜기 (안드로이드에서 특히)

8. 종이 접수로 전환 (최후 수단)

언제 — 폼이 5분 넘게 안 열리거나, 직원 로그인이 안 되거나, 네트워크가 현장 전체에서 끊겼을 때.

받을 것

항목 비고
이름
휴대전화 번호 어르신 폰 화면을 직접 보고 적습니다
사시는 동 남동구 관내만
성별
생년월일 8자리
동의 3종 서명 이용약관 · 개인정보 수집·이용 · 보건소 제3자 제공

동의서는 반드시 종이로 받습니다. 나중에 직원이 폼에 대신 넣으면 어르신 본인이 동의를 누른 기록이 남지 않습니다. 종이 서명이 그 자리를 대신합니다.

복구할 때

  1. 네트워크가 돌아오면 직원 모드에서 종이 순서대로 입력합니다
  2. 입력하면서 번호를 다시 한 번 확인합니다 (이 단계에서 오기입이 제일 많습니다)
  3. 종이는 버리지 말고 보관합니다 — 동의 증빙입니다
  4. 어르신께 문자가 늦게 간다고 미리 안내해 둡니다

9. 어르신께 드리는 말 (상황별)

상황 이렇게
접수 완료 "신청 다 됐습니다. 바로 참여 확정이에요. 잠시 뒤 문자가 갈 거예요."
문자가 늦음 "신청은 끝났어요. 문자가 좀 늦을 수 있는데, 앱스토어에서 '맬리브레인' 찾아서 받으셔도 됩니다."
폼이 안 열림 "기계가 잠깐 느리네요. 종이로 먼저 받아두고 저희가 넣어드릴게요."
관외 거주 "이 교실은 남동구에 사시는 분만 참여하실 수 있어요. 앱은 그냥 쓰실 수 있고, 사시는 곳 보건소에도 비슷한 교실이 있을 거예요."
앱이 안 깔림 "폰이 좀 오래된 것 같아요. 가족분 도움 받으셔도 되고, 보건소로 전화 주시면 도와드릴게요."

쓰지 말 것 — "승인", "대기", "서버", "오류", "에러". 어르신에게는 전부 "기계가 느리다"로 바꿔 말합니다.

10. 어디까지가 현장, 어디부터 전화

현장에서 해결 담당자에게 전화
폼이 안 열림 브라우저·네트워크 바꿔보기 10분 넘게 전 직원 폰에서 안 될 때
로그인 안 됨 번호 확인 등록된 직원인데 계속 안 될 때
문자 안 옴 §3 전부 한 사람이 아니라 여러 명이 안 올 때
잘못 등록 되돌리기 남의 번호로 나갔을 때 즉시
중복 되돌리기 —
앱 연결 안 됨 §7 번호도 맞고 신청도 있는데 안 될 때

연락처 {개발 담당} · {운영 담당} · 남동구 보건소 {전화번호}

전화할 때는 번호·이름·시각·화면 캡처를 준비해 주세요. "안 돼요"만으로는 원인을 못 찾습니다.

부록. 현장에서 지킬 세 가지

  1. 번호는 어르신 폰 화면을 직접 보고 넣는다. 받아적지 않는다.
  2. 동의 3개는 어르신이 직접 누른다. 직원이 대신 누르지 않는다.
  3. 막히면 5분 안에 종이로 전환한다. 어르신을 세워두고 고치지 않는다.
