# 4기 미리 신청 핸드오프 (v4 · 2026-11-10)

남동구 보건소 치매예방교실 앱 홈의 3기 리포트 배너 자리를 '4기 미리 신청하기' 고정 배너로 바꾸고, 배너에서 4기 신청까지 이어지는 흐름입니다. 사용자가 어르신이라 한 화면에 한 가지 일만 두고, 모든 화면이 스크롤 없이 들어가게 만들었습니다.

## 흐름 요약
- 홈 배너(고정, '내년 2월 1일 시작 예정이에요', 달력 2027년 2월 1일) 탭 → 신청 상태 조회
- 3기 등록 · 미신청 → S1 신청 화면(교실 요약 + 신청자 정보) → S1-1 약관 시트 [동의하고 신청하기] → S2 완료(맬리 폭죽)
- 이미 신청 → S3 신청 내용 · 3기 미등록 → S4 웹 신청폼 안내 · 마감 → S5 · 조회 실패 → S0-E
- 3기 미등록자 웹 신청서: https://meli.health/invitations/dementia
