# 정책서

남동구 보건소 치매예방교실 · 4기 미리 신청 (홈 배너 → 신청 → 완료) · v4 · 2026-11-10

## 1. 목적과 범위

3기 종료 리포트는 볼 사람은 대부분 봤습니다(11/9 기준 열람 243명, 3기 932명 중 26%). 같은 홈 배너 자리를 4기 미리 신청 배너로 바꿔 재등록을 늘립니다. 재등록 목표는 280명이고, 11/9 기준 사전등록은 137명입니다.

- 이번 범위: 홈 배너 1개, 4기 신청 화면(교실과 신청자 정보 확인)과 약관 시트, 신청 완료, 신청 내용, 미등록자 안내, 마감 안내, 전화 문의
- 설계 원칙: 어르신이 스크롤하지 않도록 한 화면에 한 가지 일만 둡니다. 모든 화면이 375 × 812에서 스크롤 없이 들어가고, 주요 버튼은 하단에 고정합니다.
- 범위 밖: 홈 전체를 쉬는 기간 모드로 바꾸는 작업, 멈춘 순위, 활동 잠금, D-day 표기


## 2. 사용자 상태 정의

배너를 누를 때마다 서버에 신청 상태를 조회하고, 결과에 따라 이동할 화면을 정합니다. 배너 모양은 상태와 상관없이 같습니다.

| 상태 코드 | 조건 | 배너 탭 시 |
|---|---|---|
| ELIGIBLE | 3기 등록 정보(이름, 연락처)가 있고 4기 신청 기록이 없음 | S1 신청 화면 |
| APPLIED | 4기 신청 기록이 있음 (앱 또는 웹 신청폼, 계정 연결된 경우) | S3 신청 내용 |
| NO_PRIOR | 3기 등록 정보가 없거나, 이름·연락처 중 하나라도 비어 있음 | S4 신청서 안내 시트 → 웹 신청서 (meli.health/invitations/dementia) |
| CLOSED | 신청 기간이 끝났거나 정원이 찼음 | S5 마감 안내 |
| 조회 실패 | 네트워크 끊김, 서버 오류, 응답 5초 초과 | 홈에 머물고 토스트 (S0-E) |


## 3. 배너 노출 정책

- 노출 대상: 로그인한 모든 사용자. 신청 상태에 따라 숨기거나 문구를 바꾸지 않습니다.
- 노출 위치: 홈 상단, 기존 3기 리포트 배너 자리. 3기 리포트 배너는 같은 배포에서 내립니다.
- 노출 기간: 배포일부터 신청 마감일까지 마감일 확인 필요. 마감 후에는 서버 설정으로 내리고, 앱 업데이트 없이 끌 수 있어야 합니다.
- 문구는 날짜만 쓰고 D-day는 넣지 않습니다. 서브 문구는 '내년 2월 1일 시작 예정이에요', 달력 아이콘은 '2027년 / 2월 / 1일'로 연도를 보여줍니다.
- '내년'은 2026년 안에서만 맞는 말이라, 배너가 2027년 1월 1일 이후에도 남아 있으면 서브 문구를 '2월 1일 시작 예정이에요'로 바꿉니다. 앱 업데이트 없이 서버에서 바꿀 수 있어야 합니다.


## 4. 신청 정책

- 3기 등록 정보(이름, 연락처, 사는 동)를 그대로 써서 신청합니다. 앱에서 따로 입력받지 않습니다.
- 정보가 바뀐 사용자는 앱에서 고칠 수 없고, 치매안심센터 전화로 안내합니다(S6).
- 신청 순서는 신청 화면(교실과 신청자 정보 확인) → 약관 시트입니다. 약관 시트의 [동의하고 신청하기]가 실제 신청 요청입니다.
- 필수 동의 2개(개인정보 수집·이용, 제3자 제공)에 모두 체크해야 [동의하고 신청하기]가 켜집니다. '모두 동의해요' 한 번으로 둘 다 체크됩니다. 기수마다 동의를 새로 받습니다.
- 동의하지 않으면 신청할 수 없습니다. 버튼 아래에 '필수 항목에 모두 동의해야 신청할 수 있어요'를 보여줍니다.
- 한 계정은 4기에 한 번만 신청할 수 있습니다. 중복 요청은 서버가 막고 S3로 보냅니다.
- 신청 취소는 앱에서 받지 않고 치매안심센터 전화로 처리합니다.
- 거주지(남동구)는 앱에서 막지 않고 보건소가 사후 확인합니다 확인 필요


## 5. 알림 정책

- 개강 전날(2027년 1월 31일) 신청자 전원에게 문자를 보냅니다. 화면에는 '개강 전날 문자로 보내요'로 안내합니다.
- 신청 직후 완료 문자를 보낼지 정해야 합니다 확인 필요. 테스트는 반드시 본인 번호로만 합니다.

| 상황 | 처리 | 화면 |
|---|---|---|
| 배너 탭 후 조회 응답 대기 | 배너에 덮개와 스피너, 그동안 다시 눌러도 무시 | S0-L |
| 배너 탭 시 상태 조회 실패 | 이동하지 않고 토스트 4초. 다시 누르면 재조회 | S0-E |

| 동의 전 [동의하고 신청하기] | 버튼을 흐리게 두고, 누르면 약관 박스를 1.6초 강조하고 안내 문구를 빨간색으로. 요청은 보내지 않음 | S1-1 |

| 전화 걸기가 안 되는 기기 | 번호를 화면에 그대로 보여줘서 직접 걸 수 있게 | S6 |


## 7. 확인이 필요한 것

- **1. 신청 데이터** 3기 회원 정보로 4기 신청 레코드를 만들 수 있는지, 기존 4기 웹 신청폼과 같은 테이블에 쌓이는지
- **2. 동의 문구와 보유 기간** 웹 신청폼의 필수 동의 문구를 그대로 쓸 수 있는지, 보유 기간이 '4기 종료 후 1년'이 맞는지
- **3. 신청 직후 문자** 앱 신청에도 완료 문자를 보낼지
- **4. 웹 신청과 앱 계정 연결** 웹 신청폼으로 신청한 체험 회원을 연락처로 앱 계정에 연결할 수 있는지
- **5. 개강일 · 마감일 · 정원** 개강 2027년 2월 1일 (월) 확정 여부(기존 앱 문구는 2월 3일), 신청 마감일, 정원 제한 여부
- **6. 치매안심센터 운영 시간** 대표번호는 032-453-6160으로 반영했어요. S6에 적은 '평일 오전 9시부터 오후 6시'가 맞는지 확인 필요
- **8. 배너 문구 교체일** 배너를 2027년 1월에도 노출하면 1월 1일에 '내년' 문구를 바꿔야 해요. 마감일이 12월 안이면 필요 없어요
- **7. 개강 전날 문자 발송일** 개강 전날인 2027년 1월 31일은 일요일이에요. 주말에 문자를 보낼 수 있는지, 금요일(1/29)로 당길지
