## 4. API 제안

개발팀 구조에 맞게 바꿔도 됩니다. 화면이 필요로 하는 값만 정리했습니다.

| 요청 | 응답과 화면 처리 |
|---|---|
| GET /cohort/4/apply-status배너 탭 시 | status: ELIGIBLE · APPLIED · NO_PRIOR · CLOSEDprofile: 이름, 연락처(가운데 가림), 사는 동 (ELIGIBLE, APPLIED)applied_at, start_date, form_url(NO_PRIOR, 현재 https://meli.health/invitations/dementia)실패·5초 초과 → S0-E |
| POST /cohort/4/applybody: consents [privacy, third_party] 와 동의 시각 | 200 → S2 · 409 이미 신청 → S3 + 토스트 · 410 마감 → S5 · 그 외/타임아웃 10초 → S1-3 |

## 6. 모션 정의 · 맬리 폭죽 (S2)

프로토타입은 지금 맬리 이미지 한 장으로 연출했습니다. 앱에서는 같은 타이밍으로 Lottie 파일을 만들어 쓰는 것을 권합니다. 고깔과 몸을 따로 움직이려면 레이어가 나뉜 원본이 필요합니다.

| 시점 | 동작 | 값 |
|---|---|---|
| 0 ms | 화면 진입 | 진입 250ms 뒤 시작 |
| 0 → 160 ms | 웅크리기 | 아래로 5px, 가로 1.10 · 세로 0.86, 5도 기울기 |
| 160 → 550 ms | 튀어 오르며 고깔 들기 | 위로 40px, 몸 -13도, 3D 회전 Y -20도, 그림자 0.55배로 작아짐 |
| 400 ms | 폭죽 터짐 | 고깔 입구에서 색종이 80개 + 140ms 뒤 30개. 위쪽 넓은 부채꼴(왼쪽 160도 ~ 오른쪽 20도), 화면 밖으로 날아가지 않게 속도를 낮춤, 중력과 공기 저항, 앞뒤로 뒤집히며 회전. 약 2.5초 뒤 화면 밖으로 사라짐 |
| 550 → 1150 ms | 착지와 반동 | 세로 0.90으로 눌렸다가 7px 한 번 더 튐 |
| 1150 ms ~ | 숨쉬기 반복 | 2.6초 주기로 위아래 5px, 그림자 함께 |
| 맬리 탭 | 다시 재생 | 처음부터 다시. 터치 영역 112 × 109 |
| 동작 줄이기 설정 | 연출 끔 | OS의 동작 줄이기가 켜져 있으면 정지 이미지만 |
