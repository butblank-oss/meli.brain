# 쉬는 기간 배너 → 4기 신청 루트 핸드오프

> 맬리브레인 4기 개편 프로토타입(`proto-4th/index.html`)에서 **쉬는 기간 회원의 홈 배너와, 배너에서 4기 신청 완료까지 이어지는 루트**를 정리한 문서예요.
> 다른 세션에서 이 문서와 프로토타입 HTML을 함께 읽고, 정책·화면설계·개발 요청 문서로 이어서 정리하는 데 쓰려고 만들었어요.
> 기준 시점: 2026-11-10 · 기준 파일: `proto-4th/index.html` (PR #18로 main 반영)

---

## 0. 다른 세션에 붙여넣을 지시문

```
butblank-oss/meli.brain 저장소의 proto-4th/handoff/쉬는기간_배너_핸드오프.md 를 먼저 읽고,
같은 폴더 기준 ../index.html (4기 개편 프로토타입)을 참고해서
"쉬는 기간 배너 → 4기 신청" 루트를 기획 문서로 정리해 줘.

- 핸드오프 문서 4장(루트)과 6장(정책)은 프로토타입 코드에서 읽어낸 사실이야. 그대로 기준으로 써.
- 8장(기존 문서와 어긋나는 점)과 10장(남은 결정사항)은 확정이 아니야. 임의로 정하지 말고 나한테 물어봐.
- 결과물은 docs/ 의 기존 문서 형식(정책·상수 표, 화면 요소 ID 표, 예외 상태 표)을 따라 .md와 .html로 만들어 줘.
```

### 프로토타입에서 이 루트를 보는 방법

1. 공개 주소를 PC 브라우저로 열면 왼쪽에 컨트롤 패널, 가운데에 폰 화면이 보여요.
2. 컨트롤 패널 **회원 상태 → "쉬는 기간"** 을 누르면 홈 상단에 배너가 나와요.
3. 배너의 **"미리 신청하기"** 버튼부터 아래 4장 순서대로 눌러 보면 돼요.
4. 컨트롤 패널 **여정 개선 → "홈 · 기수 종료 2주 전"**, **"4기 이어서 신청"** 은 진행 중 회원 쪽 진입 경로예요(4-4).

> 프로토타입 코드를 직접 읽어야 하면: `index.html` 안의 `<script type="__bundler/template">` 블록이 화면 마크업과 상태 로직이에요. JSON 문자열로 들어 있어서 파싱해서 꺼내야 읽혀요. 배너 관련 로직은 `renderVals()`의 `goClassInfo`, `applyClass`, `applyDoneHome`, `bannerLabel/Title/Sub/Cta`, `journeyVals()`의 `goReapply`, `reapplySubmit`이에요.

## 2. 회원 상태 3종

프로토타입은 회원 상태(`tier`)를 3가지로 나눠요. 배너는 **진행 중이 아닐 때만** 보여요.

| 상태 | 코드값 | 정의 | 홈 상단 제목 | 배너 |
|---|---|---|---|---|
| 진행 중 | `class` | 현재 기수(3기) 교실 회원 | 치매예방교실 26년 | 없음 |
| 쉬는 기간 | `break` | 지난 기수 회원 · 기수 사이 공백기 | 치매예방교실 · 쉬는 기간 | **4기 안내 배너** |
| 일반 | `free` | 교실 회원이 아닌 앱 단독 사용자 | 맬리브레인 | 교실 안내 배너 |

- 쉬는 기간과 일반은 **같은 무료 범위**를 써요 (활동 4가지만 열림, 16가지 중).
- 쉬는 기간에만 더 보이는 것: **지난 기수 기록 · 멈춘 순위 · 개강 D-day**.

## 3. 쉬는 기간 배너 정의

### 3-1. 위치와 노출 조건

- **위치:** 홈(오늘 탭) 최상단, "지금 할 활동" 카드 위. 카드 없이 배경 위에 놓이고, 아래에 1px 구분선이 있어요.
- **노출 조건:** `tier !== 'class'` (쉬는 기간 · 일반). 쉬는 기간이면 아래 문구, 일반이면 교실 안내 문구.
- **노출 종료:** 프로토타입에는 종료 조건이 없어요. 4기 개강일 이후 처리는 10장 결정사항이에요.
- **구성:** 라벨(초록 15px) · 제목(18px) · 보조문구(15px) · CTA 버튼(42px, 초록) · 오른쪽 새싹 캐릭터 이미지(112px).

|---|---|---|---|

## 4. 루트 (화면 흐름)

### 4-1. 전체 그림

```
[쉬는 기간 · 미신청]
 홈 배너 "미리 신청하기" ──┐
 더 해보기 잠금 카드 "4기 신청" ─┤
                         ▼
               교실 알아보기 (쉬는 기간형)
               └ 남동구 4기 카드 "남동구 교실 신청하기"
                         ▼
               4기 신청 완료  ── "확인" ──▶ 홈 (applied4 = true)
                         ▲                     │
[쉬는 기간 · 신청 완료]      │                     ▼
 홈 배너 "신청 내용 보기" ───┘         배너 문구가 "4기 신청 완료"로 바뀜
 더 해보기 잠금 카드 "4기 신청" ─┘  (신청 후에는 교실 알아보기를 건너뜀)

[진행 중 · 기수 종료 2주 전]  ← 쉬는 기간 진입 전 경로
 홈 공지 "3기가 11월 30일에 끝나요" → 4기 이어서 신청 → "이대로 신청하기" → 4기 신청 완료 → 홈
```

|---|---|---|---|---|
| R-01 | 홈 | 배너 "미리 신청하기" 탭 | 교실 알아보기로 이동. 돌아갈 화면(`back`)에 홈 저장 | `goClassInfo` |
| R-01b | 더 해보기 | 잠금 카드 "4기 신청" 탭 | R-01과 같음. `back` = 더 해보기 | `goClassInfo` |
| R-02 | 교실 알아보기 | 화면 확인 | 남동구 4기 카드만 보임 (지역 선택 영역 숨김) | `showNamdong`, `infoFree=false` |

| R-05 | 홈 | 배너 확인 | 라벨·보조문구·CTA가 신청 완료형으로 바뀜 | `bannerLabel` 등 |

## 10. 남은 결정사항

1. **배너 종료 시점** — 4기 개강일에 배너를 내리고 진행 중 상태로 바꾸는지, 신청 안 한 쉬는 기간 회원은 개강 후 일반 회원으로 넘어가는지.
2. **쉬는 기간의 시작과 끝** — 3기 종료일(11/30) 다음 날부터 4기 개강 전날까지로 볼지.
3. **확인 단계 통일** — 배너 루트도 리포트처럼 확인 바텀시트를 거칠지(D-02).
4. **신청 마감 이후** — 우선 신청 마감(12/15) 이후와 정원이 다 찬 경우 배너 문구와 CTA.
5. **명칭 · 전화번호 · 운영 주체** — D-01, D-04, D-05 통일 방식.
6. **신청 정보 변경 · 취소** — G-04, G-06의 허용 여부와 경로.
7. **D-day 표기 범위** — D-120처럼 먼 날짜도 D-day로 보여줄지, 일정 기간 전부터만 보여줄지.
8. **개강 알림** — 문자 외 앱 푸시 병행 여부, 발송 시각.
